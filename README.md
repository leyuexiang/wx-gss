# 3DGS 训练服务

基于 FlexGaussian 的 3D Gaussian Splatting 训练服务，支持多视角照片和视频输入，提供完整的 Web 管理界面。

---

## 🚀 快速开始

### 访问地址

- **前端管理界面**: http://192.168.10.148:3002
- **后端 API**: http://192.168.10.148:12524
- **API 文档**: http://192.168.10.148:12524/docs

### 启动服务

```bash
# 启动后端（Docker）
cd /home/3dgs
cp .env.example .env  # 首次部署时填写实际 API_KEY 和 Redis 地址
docker-compose up -d

# 启动前端
cd /home/3dgs/frontend
npm install
npm run dev -- --host 0.0.0.0 --port 3002
```

## ✨ 核心功能

### 1. 多视角照片训练
- 支持 ZIP 压缩包上传（包含多角度拍摄的图像序列）
- 自动 COLMAP/MASt3R 特征提取和相机位姿估计
- 灵活的训练参数配置（迭代次数、分辨率、场景类型）
- 实时训练进度和日志显示

### 2. 视频自动抽帧
- 支持格式：MP4、AVI、MOV、MKV、WebM
- 三种抽帧模式：
  - **FPS 模式**：按帧率抽取（如每秒 5 帧）
  - **时间间隔模式**：每隔 X 秒截取一帧（如 0.3 秒）
  - **总帧数模式**：指定提取总帧数（如 100 帧）
- 智能过滤：去除模糊帧和重复帧
- 时间范围裁剪：指定视频的起止时间

### 3. 单物体快速重建

在“生成”页开启“单物体重建”并选择“快速预览”，可直接上传 8–50 张照片，也可上传含多张照片的 ZIP 或视频。视频先均匀抽取约 80 帧，再按时间段选出默认 12 张主体清晰的视角；照片按文件名顺序分段选图。少视角重建使用 MASt3R，并默认以 3000 次迭代、1/2 分辨率生成快速预览。

单物体现在可以分别选择“快速预览”和“高质量重建”。高质量模式默认选择 60 个视角，支持 20–200 个目标视角，使用 COLMAP 和经过同素材对照的原版风格增密策略；相机模型、训练预算和分辨率可以调整。任务保存选帧清单、实际配置、清理前模型及固定视角图像指标。查看器显示实际训练像素尺寸，并可切换固定颜色、最高二阶球谐颜色及清理前模型。评估范围和已知限制见 [清晰度优化实施记录](docs/3DGS清晰度优化实施记录.md)。

主体区域评估、独立重建验证及图像缓存对照见 [第二轮优化记录](docs/3DGS清晰度优化第二轮记录.md)。训练默认使用 256 MiB 有界八位图像缓存，可通过高级参数 `imageCacheMB` 调整；原尺寸 COLMAP 数据准备直接复制去畸变图，避免额外 JPEG 压缩。

高质量模式还会每 1,000 次保存阶段模型和固定验证指标，可通过 `checkpointEvery` 关闭或调整。结果包额外包含验证最佳阶段，完整阶段留存在任务输出目录；阶段 PLY 不含优化器续训状态。时程对照、指标选优范围和依赖重置问题见 [第三轮记录](docs/3DGS清晰度优化第三轮记录.md)。

拍摄时保持物体和背景静止，让相机围绕物体缓慢走完一圈，主体居中、光线均匀，避免强反光和透明表面。照片建议按 `001.jpg`、`002.jpg` 的顺序命名。居中正方形裁切只减少边缘背景，不等于背景分割；如需真正的孤立物体资产，还需要另行接入前景掩码和支持掩码的训练流程。

### 4. 模型压缩优化
- 支持多种压缩算法：
  - LightGaussian
  - Mini-Splatting
  - Compact3D
- 可配置压缩级别（低/中/高）
- 质量优先模式
- 压缩前后对比（文件大小、PSNR）

### 5. 去噪与质量优化
- 不透明度过滤：移除低质量高斯点
- 尺寸过滤：清理过小/过大的高斯点
- 梯度裁剪：训练稳定性优化
- 深度正则化：提升几何一致性
- 抗锯齿：改善渲染质量

### 6. Web 管理界面
- 科技风格 UI（深色主题 + 霓虹蓝/紫配色）
- 三大模块：生成、优化、查看
- 实时进度显示和任务管理
- 模型列表和详情查看

## 🏗️ 技术架构

### 后端技术栈
- **框架**: FastAPI 0.109.0
- **任务队列**: Celery + Redis
- **容器化**: Docker + docker-compose
- **GPU 加速**: CUDA 12.8.1 + NVIDIA Container Toolkit

### 前端技术栈
- **框架**: Vue 3.4.0
- **UI 组件**: Element Plus 2.5.0
- **构建工具**: Vite 5.0.0
- **状态管理**: Pinia 2.1.7
- **路由**: Vue Router 4.2.5

### 训练引擎
- **3DGS 实现**: FlexGaussian（自适应参数、去噪优化）
- **SfM 后端**:
  - COLMAP（密集拍摄，20-500 张）
  - MASt3R（少视角，2-15 张）
- **视频处理**: FFmpeg

## 🎯 典型使用流程

### 方式 1：照片训练

1. 准备多角度拍摄的照片（建议 50-150 张）
2. 打包为 ZIP 压缩包
3. 访问前端界面，上传 ZIP 文件
4. 配置训练参数（或使用推荐参数）
5. 启动训练，实时查看进度
6. 训练完成后下载或在线查看模型

### 方式 2：视频训练

1. 录制环绕拍摄视频（建议 30-60 秒）
2. 访问前端界面，上传视频文件
3. 配置抽帧参数：
   - 选择抽帧间隔（推荐 0.3-0.5 秒）
   - 开启去模糊和去重
4. 系统自动抽帧并开始训练
5. 查看训练进度和最终模型

### 方式 3：API 调用

```bash
# 提交训练任务
curl -X POST http://192.168.10.148:12524/train \
  -H "X-API-Key: your_key" \
  -F "file=@photos.zip" \
  -F "sfm_backend=colmap" \
  -F "iterations=7000"

# 查询任务状态
curl http://192.168.10.148:12524/task/{task_id}

# 下载结果
curl -O http://192.168.10.148:12524/task/{task_id}/result
```

## 🔧 故障排查

### 前端无法连接后端

检查后端服务状态：
```bash
docker ps | grep 3dgs-api
docker logs 3dgs-api
```

### 训练失败

查看详细日志：
```bash
docker logs 3dgs-worker
```

常见问题：
- 图片数量不足（需至少 10 张）
- 图片质量差（模糊、曝光不足）
- GPU 内存不足（尝试降低分辨率）

### 视频抽帧失败

检查 FFmpeg 是否可用：
```bash
docker exec 3dgs-api ffmpeg -version
```

## 📊 性能指标

### 训练时间（参考）

| 场景类型 | 图片数量 | 分辨率 | 迭代次数 | 预计时间 |
|---------|---------|--------|---------|---------|
| 小物体 | 50 张 | 1/2 | 7000 | ~15 分钟 |
| 室内场景 | 100 张 | 1/2 | 10000 | ~30 分钟 |
| 室外场景 | 200 张 | 1/4 | 15000 | ~45 分钟 |

*基于 NVIDIA RTX 3090 测试

### 系统要求

- **最低配置**:
  - GPU: 8GB 显存（CUDA 11.8+）
  - RAM: 16GB
  - 磁盘: 50GB 可用空间

- **推荐配置**:
  - GPU: 24GB 显存（RTX 3090/4090）
  - RAM: 32GB
  - 磁盘: 100GB SSD
