# 视频抽帧生成 3DGS 模型指南

## 功能概述

现在你可以**直接上传视频文件**来生成 3DGS 模型！系统会自动从视频中抽取关键帧，然后用这些图像进行 3D 重建。

## 支持的视频格式

- ✅ **MP4** (.mp4)
- ✅ **AVI** (.avi)
- ✅ **MOV** (.mov) - Apple QuickTime
- ✅ **MKV** (.mkv)
- ✅ **WebM** (.webm)

## 三种抽帧模式

### 1️⃣ 按帧率抽取（FPS）

**适用场景：** 需要均匀采样，保证时间间隔一致

**参数：** FPS (每秒帧数)
- **1 FPS**: 每秒抽 1 帧 → 慢速运动、静态场景
- **3-5 FPS**: 每秒抽 3-5 帧 → **推荐** 适合大多数场景
- **10+ FPS**: 每秒抽 10+ 帧 → 快速运动、细节捕捉

**示例：**
```
30 秒视频，5 FPS → 约 150 帧
60 秒视频，3 FPS → 约 180 帧
```

**优点：**
- 时间分布均匀
- 容易计算结果帧数
- 适合匀速拍摄

**缺点：**
- 可能包含冗余帧（静止场景）
- 快速移动时可能跳帧

---

### 2️⃣ 按时间间隔抽取 ⭐ **推荐用于你的需求**

**适用场景：** 精确控制时间间隔，"每隔 X 秒截取一张图片"

**参数：** 间隔（秒）
- **0.1 秒**: 每 0.1 秒一帧 → 高密度采样
- **0.3 秒**: 每 0.3 秒一帧 → **推荐** 平衡质量和数量
- **0.5 秒**: 每 0.5 秒一帧 → 标准采样
- **1.0 秒**: 每 1 秒一帧 → 稀疏采样

**示例：**
```
每 0.3 秒抽一帧：
30 秒视频 → 30 / 0.3 = 100 帧
60 秒视频 → 60 / 0.3 = 200 帧

每 0.5 秒抽一帧：
30 秒视频 → 30 / 0.5 = 60 帧
60 秒视频 → 60 / 0.5 = 120 帧
```

**优点：**
- ✅ **最直观的控制方式**
- ✅ 精确控制采样密度
- ✅ 适合所有场景类型

**使用建议：**
- 室外场景、慢速环绕：0.5-1.0 秒
- 室内场景、正常速度：0.3-0.5 秒
- 物体特写、快速旋转：0.2-0.3 秒

---

### 3️⃣ 指定总帧数

**适用场景：** 已知需要多少张图，让系统均匀分布

**参数：** 总帧数
- **50 帧**: 最少推荐数量
- **100 帧**: **推荐** 平衡质量和速度
- **150-200 帧**: 高质量重建
- **300+ 帧**: 超高质量（训练时间长）

**示例：**
```
30 秒视频，抽取 100 帧 → 每 0.3 秒一帧
60 秒视频，抽取 100 帧 → 每 0.6 秒一帧
```

**优点：**
- 精确控制最终数量
- 自动均匀分布
- 适合固定数量需求

**缺点：**
- 不同长度视频，时间间隔不同
- 不够直观

## 高级配置

### 🎬 时间范围控制

**起始时间 & 结束时间**

跳过视频开头和结尾的无用部分：

```
视频总长 60 秒：
起始时间: 5 秒  → 跳过前 5 秒
结束时间: 55 秒 → 跳过后 5 秒
实际处理: 5-55 秒（50 秒）
```

**使用场景：**
- 跳过片头片尾
- 只处理关键部分
- 去除起始/结束的抖动

### 🎨 图像质量

- **低 (快速)**: JPEG 质量 60-70，处理速度快
- **中 (推荐)**: JPEG 质量 85-90，平衡质量和速度
- **高 (最佳)**: JPEG 质量 95-100，最佳图像质量

### 🔍 智能过滤

#### 去除模糊帧
- ✅ 自动检测并移除运动模糊或失焦的帧
- 基于拉普拉斯算子计算图像清晰度
- 通常能过滤掉 3-8% 的低质量帧

#### 去除重复帧
- ✅ 检测相似度过高的连续帧
- 移除静止场景中的冗余帧
- 通常能过滤掉 2-5% 的重复帧

## 最佳实践

### 📹 拍摄建议

**室外场景（建筑、街景）：**
```
- 视频长度: 30-60 秒
- 拍摄方式: 360° 环绕或直线移动
- 抽帧设置: 每 0.5 秒一帧
- 预期帧数: 60-120 帧
```

**室内场景：**
```
- 视频长度: 20-40 秒
- 拍摄方式: 缓慢环绕
- 抽帧设置: 每 0.3 秒一帧
- 预期帧数: 60-130 帧
```

**物体/人物特写：**
```
- 视频长度: 15-30 秒
- 拍摄方式: 物体旋转或相机环绕
- 抽帧设置: 每 0.2-0.3 秒一帧
- 预期帧数: 50-150 帧
```

### 🎯 参数推荐对照表

| 视频长度 | 间隔模式 | 帧率模式 | 总帧数模式 | 预期结果 |
|---------|---------|---------|----------|---------|
| 15 秒 | 0.2 秒 | 5 FPS | 75 帧 | 75 帧 |
| 30 秒 | 0.3 秒 | 3-5 FPS | 100 帧 | 100 帧 |
| 60 秒 | 0.4 秒 | 3 FPS | 150 帧 | 150 帧 |
| 90 秒 | 0.5 秒 | 2 FPS | 150-180 帧 | 150-180 帧 |

### ⚡ 性能优化

**如果视频很长（60 秒以上）：**
1. 使用"时间范围"功能，只处理关键部分
2. 适当增加抽帧间隔（0.4-0.6 秒）
3. 启用"去除重复帧"

**如果内存有限：**
1. 限制总帧数在 150 以内
2. 使用"中等"或"低"图像质量
3. 分段处理长视频

## 使用流程

### 第一步：上传视频

1. 进入"模型生成"页面
2. 拖拽视频文件或点击上传
3. 系统自动识别为视频文件

### 第二步：配置抽帧参数

**快速配置（推荐）：**
```
抽帧模式: 按时间间隔
时间间隔: 0.3 秒
起始时间: 0 秒
结束时间: 0（自动到结尾）
图像质量: 中
去除模糊帧: ✓
去除重复帧: ✓
```

### 第三步：配置训练参数

在"基础配置"和"高级配置"中设置 3DGS 训练参数（同常规流程）

### 第四步：开始生成

点击"开始生成"，系统会：
1. 上传视频 → 视频抽帧 → 图像过滤
2. COLMAP 特征提取和匹配
3. 3DGS 训练
4. （可选）自动压缩优化

## 常见问题

### Q: 视频多长比较合适？
A: **30-60 秒**最佳。太短可能帧数不够，太长处理时间长且可能冗余。

### Q: 我应该选择哪种抽帧模式？
A: 
- **新手推荐**: 按时间间隔，0.3-0.5 秒
- **需要精确控制**: 按时间间隔
- **固定数量需求**: 指定总帧数

### Q: 每隔多少秒抽一帧最好？
A: 
- **0.2-0.3 秒**: 高质量，适合细节丰富场景
- **0.3-0.5 秒**: **推荐**，平衡质量和数量
- **0.5-1.0 秒**: 快速处理，适合大场景

### Q: 抽帧后会保存原视频吗？
A: 不会。视频抽帧后，只保留提取的图像帧，原视频会被删除以节省空间。

### Q: 可以用手机拍的视频吗？
A: 可以！手机视频完全支持，建议：
- 保持稳定（使用稳定器更佳）
- 光照充足
- 缓慢移动
- 避免手抖

### Q: 需要多少帧才能生成好的 3DGS 模型？
A: 
- **最少**: 50 帧（可用但质量一般）
- **推荐**: 80-150 帧（质量好）
- **高质量**: 150-250 帧（效果最佳）

### Q: 视频抽帧比直接拍照效果好吗？
A: 各有优劣：
- **视频抽帧优势**: 连续性好、拍摄简单、不易遗漏角度
- **直接拍照优势**: 图像质量高、可精确控制每张图
- **推荐**: 视频抽帧更适合新手和快速原型

## 技术实现

当前是模拟实现，集成实际抽帧时需要使用 **FFmpeg**：

### 按帧率抽取
```bash
ffmpeg -i input.mp4 -vf fps=5 -q:v 2 output_%04d.jpg
```

### 按时间间隔抽取
```bash
# 每 0.3 秒一帧
ffmpeg -i input.mp4 -vf "fps=1/0.3" -q:v 2 output_%04d.jpg
```

### 指定总帧数
```bash
# 计算间隔并均匀抽取
ffmpeg -i input.mp4 -vf "select='not(mod(n\,N))'" -vsync 0 -q:v 2 output_%04d.jpg
```

### 时间范围控制
```bash
# 从第 5 秒到第 55 秒
ffmpeg -i input.mp4 -ss 5 -to 55 -vf fps=3 -q:v 2 output_%04d.jpg
```

### 去除模糊帧
```python
# 使用拉普拉斯算子计算清晰度
import cv2
def is_blurry(image_path, threshold=100):
    image = cv2.imread(image_path)
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    laplacian = cv2.Laplacian(gray, cv2.CV_64F)
    variance = laplacian.var()
    return variance < threshold
```
