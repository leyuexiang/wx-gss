## 1. 目标与实施原则

目标是提升手机视频生成模型的主体细节、边缘清晰度和多视角一致性，并定位模糊发生在输入、相机重建、训练、导出还是网页显示阶段。

实施原则：

1. 先建立可复现的对照，再修改算法和默认参数。
2. 同一组对照尽量只改变一个因素；多项同时变化时明确标为组合方案。
3. 优先复用已有 COLMAP、MASt3R 和 gsplat，不直接整套替换工程。
4. 保留原始输入、实际训练配置及清理前结果，确保可以复查和回退。
5. 用固定视角渲染和真实图像指标判断效果，不能仅凭高斯点数量、文件大小或训练损失判断清晰度。
6. 本机代码与服务器实际运行版本需要先核对。本文基于本机源码的发现，不能直接视为服务器历史任务的全部执行细节。

## 5. 分阶段实施内容

### 阶段一：建立基线并定位模糊环节（P0）

实施内容：

1. 核对本机和服务器源码版本、依赖版本、显卡及可用显存。
2. 查找当前任务保留的原视频、候选帧、最终选帧、重建数据、训练配置、日志和模型文件；缺失项如实登记。
3. 固定一组代表性相机，保存原始帧、实际训练图像、训练器渲染和网页显示的对照。
4. 对照使用相同相机内外参、输出尺寸和主体区域，避免缩放或不同观察角度干扰判断。
5. 固定随机种子，记录输入文件清单、参数和运行版本。
6. 建立不参与图像监督训练的验证视角；选取时考虑时间邻近和视角覆盖，避免验证集全部由近重复帧组成。

验收标准：

- 明确实际使用的图像数和训练宽高。
- 至少得到 6 个固定视角的对照，能够区分输入、训练和显示的问题。
- 已有导出模型可以单独检查，无需先重新训练。
- 缺少历史训练状态时，不声称能够精确复现历史训练过程。

### 阶段二：修正显示链路的信息损失（P0）

实施内容：

1. 复用已经包含球谐颜色的 PLY 文件，检查增加只读模型访问方式是否能满足当前查看器。
2. 对照固定颜色、二阶球谐颜色与训练器三阶球谐渲染。
3. 先核实查看器版本的实际解析和渲染能力；按已确认的能力开放配置。
4. 若完整三阶显示需要更换查看器或额外实现，单独评估，不能仅把阶数改为 3 就视为支持。
5. 核对坐标、相机、颜色范围和抗锯齿处理，避免把显示差异当作几何质量问题。

验收标准：

- 同一模型可在固定相机下比较训练渲染和网页显示。
- 网页明确使用的数据格式与球谐阶数。
- 不再无提示地把仅含固定颜色的显示等同于完整训练效果。
- 记录加载时间、显存和交互流畅度，防止显示升级导致不可接受的开销。

### 阶段三：核对参数生效并评估训练约束（P0）

实施内容：

1. 追踪界面设置到接口、任务队列、流水线和训练器的完整参数传递。
2. 复用已有配置转换模块，统一字段名称和默认值；任务保存最终生效配置。
3. 界面暂不支持的参数应明确标注，避免形成已经生效的错觉。
4. 用同一组输入，对照开启和关闭全局位置方差、尺度方差约束的结果；两类约束分开记录。
5. 记录尺寸过滤、不透明度过滤和距离过滤各自删除的点数。
6. 保留清理前、清理后两份可比较结果，核对细线、物体边缘和低不透明度细节是否被误删。

验收标准：

- 界面支持的参数与日志、最终训练配置一致。
- 能独立评估平滑约束及各类后处理对细节的影响。
- 未经验证，不通过继续加强过滤或提前停止增密来处理所有模糊问题。
- 历史模型仍可读取；新的结果不覆盖原有对照数据。

### 阶段四：完善视频抽帧与质量模式（P1）

实施内容：

1. 将重建质量目标与场景类型分开，允许单物体选择快速预览或高质量重建。
2. 快速预览继续使用少量视角；高质量模式优先复用普通视频流程及 COLMAP。
3. 首轮尝试保留约 50–100 张有效视角，最终数量受视频内容、覆盖范围和重建成功情况影响。
4. 复用现有清晰度评分与过滤，按时间段挑选清晰帧，兼顾主体质量、相邻重叠和全程覆盖。
5. 选择性增加候选取样密度，先在缩小图像上评分，再保存选中的高质量图像，避免不必要的解码和内存开销。
6. 去重同时考虑视角变化；模糊过滤导致覆盖缺口时应补选候选帧。
7. 记录候选数、模糊剔除数、重复剔除数、最终保留数和对应时间戳。
8. 对失焦、运动模糊或曝光异常给出采集建议；图像编码质量调高不应描述为能恢复已经丢失的细节。

验收标准：

- 高质量单物体任务可以超过 15 帧，并走适配的重建流程。
- 不直接扩大 MASt3R 全连接匹配的图片上限，避免显存随配对数量快速增长。
- 有效帧不足时给出明确原因，发生过滤回退时保留记录。
- 结果包含选帧预览或可供检查的清单，能够确认主体和视角覆盖。

### 阶段五：有效分辨率与相机重建（P1）

实施内容：

1. 记录原图、去畸变图像和训练图像的实际尺寸，以及对应相机内参。
2. 将最大图像尺寸和训练降采样统一纳入配置，避免不透明的连续缩小。
3. 显示实际训练尺寸；降采样数值 `4` 显示为宽高各 1/4，避免误读为画质等级。
4. 在同一输入下比较 1/4 与 1/2 分辨率；原始分辨率在确认显存预算后再评估。
5. 核对缩放、裁切和去畸变后的内参变换；重点检查 MASt3R 输入处理到原图坐标的映射。
6. COLMAP 记录注册率、重投影误差和轨迹异常。注册率可先以不低于 90% 作为排查目标，不能单独用其证明相机准确。
7. MASt3R 输出每张图的位姿不等同于位姿全部准确，不把全量输出比例作为精度指标。

验收标准：

- 能回答每个任务到底使用了多大图像训练。
- 尺寸变化后，图像与相机内参一致。
- 同一有效分辨率、同一相机的数据可用于公平对照。
- 无法达到重建质量目标时，记录问题视角并优先修正输入或位姿。

### 阶段六：训练策略与预算对照（P1）

实施内容：

1. 在固定的数据集、验证集和训练分辨率下，保留现有 MCMC 策略作为对照。
2. 增加 gsplat 的原版风格增密策略（DefaultStrategy）作为可选方案。
3. 完整适配策略的梯度保留、增密调用顺序及优化器更新流程，不能仅替换策略类名称。
4. 首轮比较 5,000 和 15,000 次训练，再根据收敛和资源情况决定是否增加至 30,000 次。
5. 记录学习率、增密起止时间及高斯数量变化；迭代预算变化引起的调度差异也必须登记。
6. 根据服务器实际可用显存限制点数、图像尺寸和缓存，而不是只按显卡标称容量设置。
7. 对当前逐步读取图像的方式评估有界缓存，先测内存占用再实施，避免把全部高分辨率数据无条件常驻内存。

验收标准：

- 不预设某种策略一定更好，以固定视角结果和验证指标选取默认方案。
- 记录细节、漂浮点、训练时间、模型大小和显存峰值。
- 对照结果能复现；显存不足时保留原参数与失败原因，不悄悄降低分辨率。

### 阶段七：针对剩余问题做专项优化（P2）

仅在前述阶段仍存在对应问题时实施：

- 相机位置或方向不准：评估位姿微调，并限制其偏离初始估计的幅度。
- 几何重影或漂浮点：检查 MASt3R 深度置信度、无效深度过滤、尺度一致性和深度约束；不直接引入新深度模型。
- 手机自动曝光变化明显：评估每个视角的曝光或颜色校正，避免破坏颜色一致性。
- 主体被背景干扰：评估前景掩码及支持掩码的训练损失；居中正方形裁切不等于背景分割。
- 反光或透明材质：结合柔和照明与显示方式判断可改善范围，不承诺仅靠增加点数恢复全部外观。

## 6. 对照实验安排

| 编号 | 对照内容 | 固定条件 | 用途 |
| --- | --- | --- | --- |
| A0 | 当前模型与现有显示 | 现有模型文件、固定相机 | 保存问题基线 |
| A1 | 固定颜色、球谐颜色及训练器渲染 | 同一模型、相机和尺寸 | 定位显示信息损失，无需重新训练 |
| A2 | 全局方差约束开关 | 同一输入、种子、策略、尺寸和训练预算 | 判断训练约束影响 |
| A3 | 后处理前后 | 同一次训练结果 | 判断误删和漂浮点的权衡 |
| A4 | 1/4 与 1/2 分辨率 | 同一输入、位姿、策略和训练预算 | 判断细节是否主要受像素尺寸限制 |
| A5 | MCMC 与原版风格增密 | 同一准备好的数据集、尺寸及预算 | 比较训练策略 |
| A6 | 30 与 60 个有效视角 | 同一视频、均使用 COLMAP、其余配置一致 | 评估增加视角的收益 |
| A7 | 原有快速流程与最终高质量流程 | 同一视频及统一的评估视角 | 评估组合方案，不将收益归因于单项修改 |

12 视角 MASt3R 与 60 视角 COLMAP 的直接比较同时改变了帧数和位姿求解方法，只能作为完整工作流对照。

## 7. 验证指标与最终验收

### 7.1 指标要求

- 峰值信噪比（PSNR）和结构相似性（SSIM）：在相同验证图像、相机、像素尺寸、颜色范围及裁切区域上计算。
- 主体区域指标与全图指标分别记录，主体区域定义保持一致，防止背景占比掩盖主体模糊。
- 固定视角观察物体边缘、文字、纹理、遮挡和漂浮点，同时检查未作为图像监督输入的视角。
- 记录训练耗时、显存峰值、点数、导出大小及网页加载表现。
- 当前启发式质量评分仅保留为运行参考，不能替代图像验证，也不能把高点数或低显存直接解释为高清晰度。

### 7.2 阶段目标

最终方案需要满足：

1. 输入、实际参数、运行版本和评估过程可追溯。
2. 至少一组相同验证条件下的主体细节得到明确改善，且没有明显新增几何重影或主体缺失。
3. 可将 PSNR 提升约 1 dB 或 SSIM 提升约 0.01 作为初始改进目标；这是待验证目标，不是效果承诺，也不是几何准确性的充分条件。
4. 同一模型在训练器和网页中的显示差异有解释，使用的球谐阶数和精度限制明确。
5. 快速预览与高质量模式有独立说明，用户能够看到有效帧数和实际训练尺寸。
6. 未达到改进目标时保留失败结论，不通过更换验证集、缩小输出尺寸或调整主体区域掩盖问题。

## 8. 发布与回退

1. 在独立任务目录完成对照，保留当前模型和历史任务。
2. 新增训练策略与质量模式先作为可选项，验证后再考虑调整默认值。
3. 记录服务器部署前后的版本及最终配置，部署后使用真实模型确认接口、训练任务和网页显示一致。
4. 任一改动导致明显质量回退、显存溢出或查看器兼容问题时，恢复上一组已验证配置。
5. 保留已有 `.splat` 文件读取能力；新增显示格式不能导致历史模型无法打开。
