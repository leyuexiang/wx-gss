# 新绿幕茶罐视频试验（2026-10-29）

## 结论与边界

新视频已完成独立前景重建试验。针对白色罐身、金色边缘和绿色盖顶图案生成自动轮廓，背景特征屏蔽后完成 120/120 视角合并重建和 7,000 次训练。导出模型主要绿幕已去除、绿色盖顶保留，大字和部分背面文字可辨；部分侧面仍有重影，金属盖在强反光角度模糊，不能宣称全部细节恢复或已达到最终高清验收。

本轮没有修改生产训练默认值，没有覆盖历史推荐模型。轮廓属于当前茶罐的自动原型，未经逐像素人工确认；不能将其作为通用绿幕分割功能。

## 分割与几何

1. 在中央区域定位白色罐身，排除低饱和但偏绿的亮背景；仅保留罐身的主连通分量。
2. 利用红色分量更强的金色边缘恢复粗凸轮廓，保留轮廓内部的绿色盖顶图案。
3. 在半尺寸图像上用图割（GrabCut）细化轮廓。只允许在粗轮廓附近扩展，修正圆形盖边及转台误入。
4. 特征掩码向内腐蚀 20 像素，只用于排除背景和轮廓交界特征。原始颜色图保持不变。
5. 原图和完整主体掩码使用同一相机模型执行去畸变；掩码插值后以 128 为固定阈值二值化，再按实际训练图摘要、尺寸重新建立清单。

四页主体裁剪联系表覆盖全部 120 帧，完成缩略图级检查。主要绿布已排除，绿色盖顶保留；部分帧罐底的灰色转台反光仍被掩码包含，盖顶反光强的个别帧边缘也不完整。自动清单继续标记 `reviewed: false`，不把缩略图检查写成逐像素人工确认。首轮训练保留这些缺陷，用来观察实际影响，后续精修应冻结修正后的掩码再另做对照。

## 训练与评估约定

- 7,000 次、默认增密策略、种子 42、球谐阶数 3、点数上限 1,000,000、清理阈值 0.005，距离分位 100。
- 使用刚性相机归一化，仅缩放相机中心和点云，保留旋转正交性。
- 原视频 1920 × 1080；去畸变后实际训练为 1845 × 1037，不再额外降采样。
- 105 张训练、按排序每 8 张留出一张，共 15 张验证。位姿和初始点云使用全部图像，不能称为完全未见视角测试。
- 仅在内存中将参考图背景变黑；全图颜色与结构损失之外，对渲染透明度施加前景/背景分别归一化的轮廓损失，权重 0.1。原始文件未涂黑或覆盖。
- 首轮关闭双边网格和稀疏深度，不将多个改动的效果混合归因。
- 额外报告真正前景像素的峰值信噪比（PSNR）、主体外平均透明度、主体内透明度误差及轮廓交并比（IoU）。黑色背景占比大，不能只用全图分数说明清晰度。
- 指标依赖自动掩码，不能替代人工观察；本轮与旧视频的曝光、主体像素大小、背景定义及验证集不同，不能直接比较分数来宣称算法提升。

## 复现入口

在具备当前项目依赖、重建工具和显卡的环境中执行。所有输出目录须使用新名称，以下路径为示例，不能覆盖现有试验。

```bash
python3 scripts/prepare_greenscreen_video.py \
  /data/quality-inputs/greenscreen-20261029.mp4 \
  /data/quality-audits/greenscreen-120-new \
  --views 120 --candidates-per-view 2

python3 scripts/run_greenscreen_trial.py \
  /data/quality-audits/greenscreen-120-new /data/tasks/NEW_TASK_ID \
  --phase all --iterations 7000
```

默认仅准备，不训练；`--phase all` 执行完整试验。需要复用已验证几何时使用 `--reuse-task`，要求其 `colmap/merged_refined` 存在且全部原图摘要一致。注册率低于 90% 时拒绝开始训练。原视频、图像、模型及试验输出均存放共享数据目录，不提交到代码仓库。
