## 1. FlexGaussian 简介

### 1.1 项目信息

- **GitHub**: https://github.com/Supercomputing-System-AI-Lab/FlexGaussian
- **论文**: FlexGaussian: Flexible Gaussian Splatting Compression
- **主要功能**: 高效压缩 3D Gaussian Splatting 模型

### 1.2 核心特性

| 特性 | 说明 | 效果 |
|------|------|------|
| **高压缩比** | 50-100× 压缩 | 44MB → 0.5-1MB |
| **快速解压** | GPU 实时解码 | < 10ms |
| **质量保持** | PSNR 下降 < 1dB | 视觉无损/轻微损失 |
| **灵活配置** | 多级压缩率 | 从轻度到极致 |

### 1.3 压缩原理

```
原始 PLY (44MB)
  ↓
特征提取（位置、颜色、形状）
  ↓
量化编码（8/16-bit 量化）
  ↓
熵编码（Huffman/Arithmetic）
  ↓
压缩文件 (0.5-2MB)
```

**技术要点**：
- 球谐系数量化（最大压缩空间）
- 位置编码优化（八叉树空间分割）
- 不透明度阈值过滤（删除低贡献点）

## 3. 使用方法

### 3.1 命令行使用

#### 基础压缩
```bash
python compress.py \
  --input point_cloud.ply \
  --output compressed.bin \
  --quality high
```

#### 参数说明
```bash
--input: 输入 PLY 文件
--output: 输出压缩文件
--quality: 压缩质量
  - high: 高质量（压缩比 30-50×，PSNR -0.5dB）
  - medium: 中等（压缩比 50-70×，PSNR -1.0dB）
  - low: 低质量（压缩比 80-100×，PSNR -2.0dB）
```

#### 解压缩
```bash
python decompress.py \
  --input compressed.bin \
  --output decompressed.ply
```

---

### 3.2 Python API 使用

```python
from flexgaussian import compress, decompress

# 压缩
compress(
    input_path='point_cloud.ply',
    output_path='compressed.bin',
    quality='high',
    # 可选参数
    opacity_threshold=0.1,      # 过滤低不透明度点
    quantization_bits=8,        # 量化位数（8/16）
    use_huffman=True            # 使用 Huffman 编码
)

# 解压
decompress(
    input_path='compressed.bin',
    output_path='decompressed.ply'
)
```

**方案 B：后期手动压缩**

创建压缩脚本 `/home/3dgs/scripts/compress_gaussian.sh`：

```bash
#!/bin/bash
# 高斯模型压缩脚本

INPUT_PLY="$1"
OUTPUT_BIN="${2:-${INPUT_PLY%.ply}_compressed.bin}"
QUALITY="${3:-high}"

if [ -z "$INPUT_PLY" ]; then
    echo "用法: $0 <input.ply> [output.bin] [quality]"
    echo "质量: high | medium | low"
    exit 1
fi

if [ ! -f "$INPUT_PLY" ]; then
    echo "错误: 文件不存在: $INPUT_PLY"
    exit 1
fi

echo "==> 压缩高斯模型..."
echo "输入: $INPUT_PLY"
echo "输出: $OUTPUT_BIN"
echo "质量: $QUALITY"
echo ""

# 获取原始文件大小
ORIGINAL_SIZE=$(du -h "$INPUT_PLY" | cut -f1)
echo "原始大小: $ORIGINAL_SIZE"

# 执行压缩
python /home/3dgs/FlexGaussian/compress.py \
    --input "$INPUT_PLY" \
    --output "$OUTPUT_BIN" \
    --quality "$QUALITY"

# 显示压缩结果
if [ -f "$OUTPUT_BIN" ]; then
    COMPRESSED_SIZE=$(du -h "$OUTPUT_BIN" | cut -f1)
    RATIO=$(echo "scale=1; $(stat -c%s "$INPUT_PLY") / $(stat -c%s "$OUTPUT_BIN")" | bc)
    echo ""
    echo "✓ 压缩完成！"
    echo "压缩后大小: $COMPRESSED_SIZE"
    echo "压缩比: ${RATIO}×"
else
    echo "✗ 压缩失败"
    exit 1
fi
```

**使用示例**：
```bash
# 高质量压缩
./compress_gaussian.sh point_cloud.ply

# 自定义参数
./compress_gaussian.sh input.ply output.bin medium

# 批量压缩
for f in *.ply; do
    ./compress_gaussian.sh "$f"
done
```

## 4. 压缩配置方案

### 4.1 压缩质量对比

| 配置 | 压缩比 | PSNR 损失 | 视觉效果 | 适用场景 |
|------|--------|-----------|----------|----------|
| **无损** | 5-10× | 0 dB | 完全一致 | 存档、专业展示 |
| **高质量** | 30-50× | -0.3~0.8 dB | 几乎无差异 | 日常使用 ⭐ |
| **中等** | 50-70× | -1.0~1.5 dB | 轻微损失 | Web 展示 |
| **低质量** | 80-100× | -2.0~3.0 dB | 明显损失 | 预览、缩略图 |
| **极致** | 100-200× | -3.0+ dB | 严重损失 | 仅做参考 |

### 4.2 参数配置详解

#### 量化位数（Quantization Bits）

```python
# 16-bit: 高质量，压缩比较低
compress(..., quantization_bits=16)  # 压缩比 ~30×

# 8-bit: 平衡，推荐
compress(..., quantization_bits=8)   # 压缩比 ~60×

# 4-bit: 激进，质量下降明显
compress(..., quantization_bits=4)   # 压缩比 ~100×
```

**建议**：
- 球谐系数：8-bit（颜色量化，肉眼不敏感）
- 位置坐标：16-bit（几何精度要求高）
- 不透明度：8-bit（过渡平滑即可）
- 旋转四元数：16-bit（方向精度重要）

---

#### 不透明度阈值（Opacity Threshold）

```python
# 保守：仅删除完全透明点
compress(..., opacity_threshold=0.01)  # 删除 ~2%

# 标准：删除低不透明度点
compress(..., opacity_threshold=0.1)   # 删除 ~10-15% ⭐

# 激进：删除更多点
compress(..., opacity_threshold=0.2)   # 删除 ~20-30%
```

**效果**：
- 阈值越高，文件越小，但可能丢失细节
- 结合后期清理脚本，可以先清理再压缩

---

#### 熵编码（Entropy Coding）

```python
# Huffman: 快速，压缩比一般
compress(..., use_huffman=True)

# Arithmetic: 慢一些，压缩比更高
compress(..., use_arithmetic=True)

# 无编码：最快，仅量化
compress(..., use_encoding=False)
```

**建议**：日常使用 Huffman，追求极致时用 Arithmetic

---

### 5.2 API 接口扩展

在 `/home/3dgs/app/main.py` 添加压缩端点：

```python
@app.post("/train/{task_id}/compress", dependencies=[Depends(require_api_key)])
def compress_result(
    task_id: str,
    quality: Literal["high", "medium", "low"] = "high"
):
    """压缩已完成任务的 PLY 文件
    
    参数：
    - task_id: 任务 ID
    - quality: 压缩质量（high/medium/low）
    
    返回：
    - compressed_size: 压缩后大小（bytes）
    - compression_ratio: 压缩比
    - download_url: 压缩文件下载地址
    """
    status = read_status(task_id)
    if status["status"] != "done":
        raise HTTPException(status_code=409, detail="task not done")
    
    tdir = task_dir(task_id)
    ply_path = os.path.join(tdir, "output", "point_cloud.ply")
    compressed_path = os.path.join(tdir, "output", "point_cloud_compressed.bin")
    
    if not os.path.exists(ply_path):
        raise HTTPException(status_code=404, detail="PLY file not found")
    
    try:
        from flexgaussian import compress
        compress(
            input_path=ply_path,
            output_path=compressed_path,
            quality=quality
        )
    except ImportError:
        raise HTTPException(status_code=501, detail="FlexGaussian not installed")
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
    
    original_size = os.path.getsize(ply_path)
    compressed_size = os.path.getsize(compressed_path)
    ratio = original_size / compressed_size
    
    return {
        "original_size": original_size,
        "compressed_size": compressed_size,
        "compression_ratio": round(ratio, 1),
        "download_url": f"/train/{task_id}/compressed"
    }


@app.get("/train/{task_id}/compressed", dependencies=[Depends(require_api_key)])
def get_compressed_result(task_id: str):
    """下载压缩后的高斯模型"""
    path = os.path.join(task_dir(task_id), "output", "point_cloud_compressed.bin")
    if not os.path.exists(path):
        raise HTTPException(status_code=404, detail="compressed file not found")
    return FileResponse(
        path,
        media_type="application/octet-stream",
        filename=f"3dgs_{task_id}_compressed.bin"
    )
```

## 7. 常见问题

### Q1: 压缩会影响渲染速度吗？

**A**: 不会。解压后的数据结构与原始 PLY 相同，渲染性能一致。

---

### Q2: 压缩文件可以直接在 SuperSplat 中打开吗？

**A**: 不行。需要先解压为 PLY 格式：
```bash
python decompress.py compressed.bin decompressed.ply
```

---

### Q3: 能否在训练时直接生成压缩文件？

**A**: 可以，集成方案见第 5 章。但建议保留原始 PLY，以便后续调整压缩参数。

---

### Q4: 压缩后还能再优化吗？

**A**: 可以。压缩前先用 post_process.py 清理杂点，可以进一步减小文件大小。

**推荐流程**：
```
训练 → 清理杂点 → 压缩
```

---

### Q5: FlexGaussian 与其他压缩方法对比？

| 方法 | 压缩比 | 质量 | 解压速度 | 兼容性 |
|------|--------|------|----------|--------|
| **ZIP** | 2-3× | 无损 | 快 | 通用 |
| **SPLAT 格式** | 1.4× | 无损 | 最快 | Web only |
| **FlexGaussian** | 50-100× | 轻微损失 | 快 | 需解压 ⭐ |
| **自定义量化** | 10-30× | 可控 | 中等 | 需实现 |

   ```python
   # 将 float32 量化为 int8
   def quantize_float32_to_int8(data, min_val, max_val):
       scale = 255 / (max_val - min_val)
       return ((data - min_val) * scale).astype(np.int8)
   ```
