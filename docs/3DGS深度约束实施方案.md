# 3DGS 深度约束实施方案

## 可行性与目标

可以从视频抽帧估计深度图，并在 3DGS 训练时约束高斯的空间位置。它适合辅助处理漂浮点、局部面层错位和弱纹理几何，但不能替代正确相机、前景标注或未拍到的背面、底部信息。

当前红罐的半主体截断属于掩码错误，深度约束无法自动撤销错误的背景透明度惩罚。盖顶也存在绿色反射，直接按深度或绿色阈值删除像素都可能误伤。因此需要分开完成“轮廓确认”和“深度约束几何”。

本文件是可执行的后续实验方案，尚未生成单目深度图，也未安装或下载新的深度模型。

## 可选来源

| 来源 | 能提供什么 | 当前限制 |
| --- | --- | --- |
| COLMAP 稀疏观测 | 和相机几何同约定的少量深度锚点 | 无法覆盖整个盖顶或纯色区域；错误观测仍需过滤 |
| 单目深度估计，例如 Depth Anything V2 | 每帧较稠密的深度先验 | 通常是相对深度；尺度、偏移及跨视角一致性不能直接假设 |
| 多视角稠密深度 | 从跨视角匹配推断几何 | 转台需要排除静止背景；金属反光、遮挡仍会造成错误 |
| 实测深度 | 有设备标定时可提供距离依据 | 需要与 RGB 相机对齐，反光表面仍可能缺测 |

本次优先试验相对单目深度与可靠稀疏锚点结合。不会默认认为灰度值是米，也不会把彩色深度可视化图片直接当作训练数值。

## D0：冻结参考与检查现有分支

- 固定共享相机任务、实际去畸变图、101 张共同训练图和 14 张共同验证图。
- 完成盖顶、底部边缘复查，记录掩码自动生成、几何先验及人工确认状态。
- 保留不启用深度的同条件基线。已有旧素材稀疏深度长训练曾回退，详见 [长训练记录](3DGS去杂云长训练记录.md)，不能省略新素材对照。
- 核对现有 MASt3R 皮尔逊相关损失、稀疏逆深度损失的输入单位，不能给其中一个分支随意传入另一种深度表示。

**验收**：参考图、掩码、相机、源码和监督划分均有摘要；不同实验只有声明的约束差异。

## D1：少量帧深度可视化与尺度对齐

1. 先选正面、背面、强反光盖顶等 6–8 个诊断视角，不直接启动全量长训练。
2. 深度估计输入为实际去畸变图，记录模型、权重摘要、推理尺寸及预处理，保持相机内参和空间像素对应。
3. 保存浮点深度/逆深度数组和有效掩码，另外生成供查看的深度彩图。
4. 以同一相机坐标下可靠稀疏观测对齐相对深度尺度和偏移。拟合仅使用训练视角；验证深度不参与损失、尺度拟合或阈值调优。
5. 标明相机轴向深度（camera Z）或沿射线距离，转换正确后才能与渲染深度比较。
6. 检查罐身是否呈连续曲面，盖顶是否被预测成绿幕，桌面是否与主体粘连，以及相邻视角深度是否相容。

**验收**：无效值可追踪；尺度对齐有足够锚点和残差报告；不可靠视角明确跳过，不补成伪真值。

## D2：可信区域与小权重实验

- 首先只在向内收缩的罐身区域启用，盖沿、强反光、遮挡边缘和不可靠桌面不监督。
- 若模型没有原生置信度，使用重投影或跨视角一致性得到的有效区域，并标为“派生一致性”，不能伪称模型概率。
- 深度约束使用与渲染一致的深度表示，权重从小范围试验，并与轮廓透明度约束分开记录。
- 先做短预算流程检查，再对“无深度 / 仅稀疏 / 稠密先验”进行同预算、同监督集合的对照。

**验收**：每项损失及梯度有限、有效像素数量可解释；深度观测不足时拒绝启用，不静默使用整张预测图。

## D3：完整训练与发布条件

- 检查前景细节、轮廓交并比、掩码外透明度、固定相机和非拍摄角度下的孔洞、漂浮点。
- 指标参考保持相同，不能只用预测深度误差或训练损失宣布质量提升。
- 完整预算和至少两次重复后判断是否稳定；几何损伤或颜色细节回退时保留失败结论。
- 仅在轮廓和主体完整性确有改善、没有明显新增破损后发布独立候选；历史模型保留。

## 与当前轮廓工作的关系

边缘引导圆罐候选可补齐绿色盖顶并限制转台范围，但其部分圆弧包含形状先验，不是深度测量。必须先展示并复查，再作为深度试验的掩码来源。深度估计也不能让没有可靠相机定位的顶部、底部照片直接加入训练。

## 依据

- [原版 3DGS：深度正则化](https://github.com/graphdeco-inria/gaussian-splatting#depth-regularization)：已集成深度约束，同时说明不同场景可能改善、变化很小或变差。
- [Depth Anything V2 官方项目](https://github.com/DepthAnything/Depth-Anything-V2)：提供相对深度模型及独立的度量深度模型，接入时需要明确使用的输出表示。
