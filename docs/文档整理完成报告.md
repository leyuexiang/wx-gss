## 📝 文档管理规范

### 新增文档时

1. **确定文档类型**:
   - 使用文档 → `frontend/` 或根目录
   - 设计文档 → `docs/核心设计/`
   - 规划文档 → `docs/升级规划/`
   - 完成报告 → `docs/归档/已完成优化/`

2. **命名规范**:
   - 使用中文命名
   - 使用 kebab-case 或汉字
   - 文件名清晰表达内容

3. **维护索引**:
   - 在相关 README 中添加链接
   - 更新文档导航

### 归档文档时

当文档过时或完成后：
1. 移动到 `docs/归档/` 相应子目录
2. 不删除，保留历史记录
3. 从主导航中移除链接
