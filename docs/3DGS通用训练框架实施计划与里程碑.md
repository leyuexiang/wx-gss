# 3DGS 通用训练框架实施计划与里程碑

**版本**：v1.0　　**制定日期**：2026-10-29

## 1. 目标与边界

当前系统已经具备抽帧、COLMAP 重建、掩码校验、3DGS 训练、导出和网页查看流程，但白罐、红罐规则仍包含颜色、形状和位置先验。本计划将系统升级为“通用训练核心 + 场景适配器”。

通用核心负责输入标准化、质量检查、数据集构建、训练、评估和发布；适配器负责绿幕、转台、颜色先验、人物和室内场景等特殊条件。无法判断拍摄模式、反光严重或视角缺失时，系统应停止训练并说明原因。

## 2. 总体架构

```text
输入视频/照片
  → 输入标准化与来源审计
  → 拍摄模式分析
  → 抽帧与清晰度筛选
  → 前景提供器（通用分割/绿幕/人工/颜色先验）
  → 掩码传播与复查
  → 位姿和稀疏几何重建
  → 数据集标准化
  → 3DGS 训练
  → 质量门禁、评估、导出和发布
```

建议模块边界：

| 模块 | 通用职责 | 场景适配 |
| --- | --- | --- |
| `InputAdapter` | 解码、方向、尺寸、来源摘要 | 特殊编码和元数据修复 |
| `CaptureAnalyzer` | 主体尺寸、清晰度、曝光、运动分析 | 转台/相机环绕判断 |
| `FrameSelector` | 时间覆盖、清晰度、重复帧过滤 | 主体区域优先级 |
| `ForegroundProvider` | 输出二值掩码和来源清单 | 通用分割、绿幕、颜色先验 |
| `PoseProvider` | 内参、位姿、注册率、重投影误差 | COLMAP、转台、补拍定位 |
| `DatasetBuilder` | 去畸变、掩码同步、训练/验证划分 | 多相机组和裁切主点 |
| `Trainer` | 统一损失、增密、导出 | 透明度、深度、光度约束 |
| `QualityGate` | 训练前后质量门禁 | 各场景阈值和人工复核 |

## 3. 拍摄模式

| 模式 | 几何假设 | 默认流程 |
| --- | --- | --- |
| `static_scene` | 相机移动，物体静止 | 普通 COLMAP + RGB 训练 |
| `turntable_object` | 相机固定，物体稳定旋转 | 物体坐标系重建 + 前景掩码 |
| `foreground_scene` | 主体明确，背景可忽略 | COLMAP + 前景/透明度约束 |
| `mixed_motion` | 相机和物体同时运动 | 先审计，未通过则拒绝训练 |

当前白罐、红罐的颜色规则只能作为 `ForegroundProvider` 插件，不能作为默认分割器。

## 4. 里程碑

### M0：接口冻结与实验基线

- 定义输入、抽帧、前景、位姿、数据集、训练和评估接口。
- 每个任务保存 `protocol.json`、源码摘要、输入摘要和实际配置。
- 白罐、红罐逻辑迁移到适配器层。
- 保持普通全图训练默认行为不变。

**验收**：历史模型可加载；默认训练结果不变；回归测试通过；任务能记录实际适配器。

### M1：通用输入分析与抽帧

- 记录分辨率、有效主体尺寸、帧率、时长、编码和方向。
- 检测运动模糊、曝光过度、重复帧和主体出框。
- 按主体区域而不是全画面纹理排序清晰度。
- 生成可复现的选帧联系表。

**验收**：每个选中帧都有来源帧号、时间和清晰度；实际训练尺寸与原始尺寸同时显示。

### M2：通用前景分割与掩码传播

- 接入通用前景分割模型作为默认候选。
- 保留绿幕、人工关键帧和颜色先验插件。
- 支持关键帧确认、光流/跟踪传播和边缘检查。
- 区分 `sfm_mask`（可腐蚀，排除边缘特征）与 `training_mask`（保留真实轮廓）。
- 自动掩码默认标记为未复查，未复查只进入隔离实验。

**验收**：掩码清单完整、尺寸和哈希一致；面积无异常跳变；掩码外透明度和轮廓 IoU 达到素材阈值。

### M3：统一位姿与转台重建

- 普通相机环绕继续使用 COLMAP。
- 固定相机转台素材使用物体旋转坐标模型。
- 记录相机组、内参、裁切主点和补拍照片定位状态。
- 只合并有共同注册视角并经过联合优化的重建分量。
- 不能定位的顶部/底部照片保留为参考，不强行加入训练。

**首轮门槛**：注册率 ≥90%；平均重投影误差 <1 像素；最大视角空缺角 <30°。这些是初始工程门槛，不代表所有物体的几何真值。

### M4：通用训练模式与损失组合

- `static_scene` 默认使用全图 RGB 损失。
- `foreground_scene` 可启用前景黑底、透明度和背景抑制。
- `turntable_object` 使用刚性归一化和物体坐标约定。
- 双边网格、稀疏深度、位姿优化和透明度损失独立开关。
- 记录每个损失的权重、范围和评估参考。

**验收**：不同组合可复现；前景模式不改变普通模式；训练失败可恢复历史模型。

### M5：质量门禁与自动发布

**训练前**：检查帧数、主体尺寸、掩码完整性、注册率、视角覆盖、固定划分和输入摘要。

**训练后**：记录前景 PSNR/SSIM、轮廓 IoU、掩码外透明度、点数、模型大小、耗时和显存；检查主体断裂、重影、顶部/底部缺失。

不达标模型只能作为实验候选，不能替换推荐模型；PLY、SPLAT、训练视角和查看器接口必须一起验证。

### M6：跨素材验证

至少验证白色物体、红色高反光物体、黑色/低纹理物体、普通室内场景、带顶部/底部补拍物体以及一个透明或金属物体。

**通过条件**：至少四类素材使用同一核心流程；专用规则只在适配器目录；失败原因可定位到采集、掩码、位姿、训练或评估；历史模型和查看器无回退。

## 5. 质量指标

| 指标 | 初始门槛/用途 |
| --- | --- |
| 注册率 | ≥90%，训练前门禁 |
| 平均重投影误差 | <1 像素，几何诊断 |
| 最大视角空缺角 | <30°，覆盖诊断 |
| 前景 PSNR/SSIM | 同素材固定验证集比较 |
| 轮廓 IoU | 检查主体边界 |
| 掩码外透明度 | 检查背景杂云 |
| 点数、大小、显存 | 检查异常增长和资源风险 |

指标不能单独证明模型真实度；必须结合固定视角图、主体文字、边缘、顶部/底部和漂浮点检查。

## 6. 风险与回退

| 风险 | 处理 |
| --- | --- |
| 转台误当相机环绕 | 切换转台模式或拒绝训练 |
| 掩码包含绿布/转台 | 分开修正 SfM 掩码和训练掩码 |
| 反光、曝光变化 | 锁定曝光/白平衡，使用光度补偿；不能只增加训练次数 |
| 顶部/底部缺少过渡视角 | 增加斜视照片，不强行定位正俯拍照片 |
| 4K 导致耗时和显存增长 | 依据主体有效尺寸分层训练，使用有界缓存 |
| 新策略回退 | 独立任务、固定验证集、保留历史模型 |

## 7. 当前状态与下一步

| 里程碑 | 状态 |
| --- | --- |
| M0 | 首批落地：采集契约、三个专用前景适配器、实验入口协议冻结、重建门禁已验证；生产统一入口和其余阶段接口尚未完成 |
| M1 | 已有视频元信息、主体清晰度选帧和来源摘要 |
| M2 | 已定位并修复红罐半主体掩码，新增前景证据覆盖检查及冻结视角配对；盖顶、转台和通用分割尚待处理 |
| M3 | 已修复视频组内共享、跨组隔离并真实核验 122 张输入；视频注册从 115 提升到 120，尚未做画质训练对照 |
| M4 | 已有前景黑底、透明度、双边网格和稀疏深度开关 |
| M5 | 已有分散的质量检查；统一自动门禁待实现 |
| M6 | 尚未开始 |

实施顺序：先完成 M0 接口和任务协议；再把白罐、红罐迁移为适配器；随后实现拍摄模式识别、质量门禁、通用前景分割，最后进行跨素材验证。每个里程碑单独提交和测试，未通过的实验不得替换当前推荐模型。

本轮实施与限制详见 [通用训练框架验收记录](3DGS通用训练框架验收记录.md)。已经迁移的专用算法仅统一接口，没有改善其分割质量。红罐逐帧独立内参问题已修复并完成真实重建核验；下一批检查相机轨迹与实体形状，并固定共同验证视角做训练对照。不能将破损完全归因于素材，也不能仅凭注册率增加宣布画质改善。

关于转台：刚体旋转在屏蔽静止背景后可等价表述为物体坐标系中的虚拟相机运动；并非所有转台素材都必须抛弃 COLMAP。M3 要明确坐标约定、相机组和轨迹约束，验证光照变化、反射及轨迹退化，而不是仅因“转台”标签更换算法。
