    means = params["means"]

    # 简单实现：计算均值方差作为平滑度指标

```python
# 解析去噪配置
if denoise_config is None:
    denoise_config = {}

size_filtering = denoise_config.get('size_filtering', {})
enable_size_filtering = size_filtering.get('enable', False)
min_size_threshold = size_filtering.get('min_size', 0.0001)
max_size_threshold = size_filtering.get('max_size', 0.1)

# 应用尺寸过滤（在导出前）
if enable_size_filtering:
    scales = torch.exp(params["scales"])  # [N, 3] 线性尺度
    scale_norms = scales.norm(dim=1)  # [N] 尺寸范数

    size_mask = (scale_norms >= min_size_threshold) & (scale_norms <= max_size_threshold)
    removed_by_size = (~size_mask).sum().item()

    if removed_by_size > 0:
        print(f"尺寸过滤: 删除 {removed_by_size} 个高斯 (< {min_size_threshold} 或 > {max_size_threshold})")

        # 过滤参数
        for key in params.keys():
            params[key] = params[key][size_mask]
```

**效果**: 删除过小或过大的高斯点，减少噪点

## 🔄 完整数据流

### 配置生成 → 训练应用流程

```
1. 前端用户配置去噪参数
   - 不透明度阈值: 0.005
   - 尺寸过滤: 最小 0.0001, 最大 0.1
   - 梯度裁剪: 最大范数 1.0
   - 平滑权重: 0.01
   - 深度权重: 0.1
   - 抗锯齿: 启用
   ↓
2. 后端 generate_training_config() 生成配置
   - 整合前端配置 + 默认值
   - 保存到 training_config.json
   ↓
3. pipeline.py 加载配置
   - 读取 training_config.json
   - 解析 denoise 字段
   ↓
4. trainer.py 训练循环应用
   - 解析去噪配置参数
   - 启用抗锯齿渲染
   - 添加平滑正则化损失
   - 应用梯度裁剪
   ↓
5. export.py 导出时应用
   - 尺寸过滤（删除过小/过大高斯点）
   - 不透明度过滤（clean_gaussians）
   ↓
6. 生成优化的 3DGS 模型
   - point_cloud.ply
   - point_cloud.splat
```
