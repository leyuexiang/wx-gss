# 圆罐边缘候选验证记录

## 目的与实施范围

承接 [红罐掩码修复与配对验证](3DGS红罐掩码修复与配对验证.md)，本轮检查盖顶绿色反射与罐底转台残留。新增候选生成入口 `repair_red_can_masks.py --edge-guided`；历史颜色适配器和现有模型不变。

放宽绿色阈值可以找回盖顶，但真实预览中也加入了绿色背景，因此没有采用该方案。当前候选按真实边缘拟合上、下圆弧和侧面：盖沿使用绿色分量变化、罐底使用亮度边缘，侧面通过一致直线剔除条码白底对边界估计的干扰。

`app/foreground/priors/cylinder_edges.py` 仍然是针对固定拍摄红色圆罐的形状与颜色先验，不是通用分割，也不是深度估计。异常盖沿拟合会使用明确记录的截面形状先验，不能把这些区域解释为测量结果。

## 真实检查

- 固定 120 个视频帧，原图不改；两个补拍照片的掩码原样保留。
- 第一轮候选保留了盖顶、减少了转台，但发现部分侧边受条码影响向内偏移；一致直线筛选已替代普通最小二乘拟合。
- 第二轮检查剩余的 5 个覆盖失败主要落在转台上的红色反射，不能把这些像素当作必须保留的物体证据。因此后续覆盖检查明确只覆盖罐身中段，不宣称验证了罐底和盖顶。
- 第三轮 120 帧罐身中段覆盖全部通过，但完整联系表显示约 30 帧使用了上沿形状先验，其中部分仍错把前沿当上沿。已进一步约束异常高度，另存第四轮候选，不覆盖失败试验。
- 服务器来源目录分别为 `red-edge-guided-r1` 至 `red-edge-guided-r4`；均位于 `/data/quality-audits/`。源码验证目录为 `/data/quality-edge-guidance-r1`。

## 验证及限制

64 项服务器回归通过，其中新增两项测试检查合成圆罐保留盖顶、排除桌面，以及没有定位证据时拒绝输出。合成测试通过不能替代实际逐帧轮廓确认。

所有候选标注为未人工确认，质量报告区分罐身覆盖与形状先验帧数。本轮未训练或发布新 3DGS，不修改现有查看模型。后续需要关键帧或独立轮廓证据复查，不能仅因中段覆盖通过就启动默认完整训练。

用户提出的深度路线另见 [深度约束实施方案](3DGS深度约束实施方案.md)。本轮圆弧拟合不等于已经生成深度图，也不能替代深度尺度标定。
