### 6.4 后处理算法增强

#### 方案 1：基于 DBSCAN 的聚类去噪

**原理**：将高斯点聚类，删除小簇（孤立点）

**实现**：
```python
from sklearn.cluster import DBSCAN

def remove_outliers_dbscan(xyz, eps=0.05, min_samples=10):
    """使用 DBSCAN 聚类删除离群点"""
    clustering = DBSCAN(eps=eps, min_samples=min_samples).fit(xyz)
    labels = clustering.labels_
    
    # 保留最大簇
    unique, counts = np.unique(labels[labels >= 0], return_counts=True)
    if len(unique) > 0:
        main_cluster = unique[np.argmax(counts)]
        mask = (labels == main_cluster)
    else:
        mask = np.ones(len(xyz), dtype=bool)
    
    return mask
```

**效果**：
- ✅ 删除漂浮的孤立点簇
- ✅ 保留主体结构
- ⚠️ 参数需要根据场景调整

**实施难度**：⭐⭐（集成到 post_process.py）

#### 方案 2：法向量一致性过滤

**原理**：相邻高斯点的法向量应该连续，突变的点可能是噪声

**实现**：
```python
def compute_normals(xyz, k=10):
    """计算每个点的法向量（基于 k 近邻）"""
    from sklearn.neighbors import NearestNeighbors
    
    nbrs = NearestNeighbors(n_neighbors=k).fit(xyz)
    distances, indices = nbrs.kneighbors(xyz)
    
    normals = []
    for i, neighbors in enumerate(indices):
        pts = xyz[neighbors]
        # PCA 求法向量
        centered = pts - pts.mean(axis=0)
        _, _, vh = np.linalg.svd(centered)
        normal = vh[-1]  # 最小特征值对应的向量
        normals.append(normal)
    
    return np.array(normals)

def filter_by_normal_consistency(xyz, normals, threshold=0.5):
    """过滤法向量不一致的点"""
    from sklearn.neighbors import NearestNeighbors
    
    nbrs = NearestNeighbors(n_neighbors=10).fit(xyz)
    distances, indices = nbrs.kneighbors(xyz)
    
    mask = np.ones(len(xyz), dtype=bool)
    for i, neighbors in enumerate(indices):
        # 计算与邻域法向量的平均一致性
        consistency = np.abs(normals[neighbors] @ normals[i]).mean()
        if consistency < threshold:
            mask[i] = False
    
    return mask
```

**效果**：
- ✅ 删除几何不连续的噪点
- ✅ 保留表面结构
- ⚠️ 计算量较大

**实施难度**：⭐⭐⭐（需要额外依赖库）

```
质量优先：
  ├─ 纯色背景（白/黑/灰）
  ├─ 10-12 张图，360° 环绕
  ├─ 三点布光，无阴影
  └─ 相机参数锁定

速度优先：
  ├─ 简单背景
  ├─ 5-8 张图，180° 覆盖
  ├─ 自然光或单光源
  └─ 手持拍摄（注意稳定）
```
