### 1. 光流分析检测相机运动 ✅

#### `analyze_camera_motion(frame_dir, sample_rate=5)`

**功能**:
- 使用 OpenCV Farneback 光流法分析相邻帧运动
- 计算运动幅度和方向
- 检测快速运动帧
- 评估运动稳定性和一致性

**算法**:
```python
# 1. 采样帧对（降低计算量）
# 2. 计算稠密光流
flow = cv2.calcOpticalFlowFarneback(
    img1, img2, None,
    pyr_scale=0.5, levels=3, winsize=15,
    iterations=3, poly_n=5, poly_sigma=1.2
)

# 3. 计算运动幅度和方向
magnitude, angle = cv2.cartToPolar(flow[..., 0], flow[..., 1])
avg_magnitude = np.mean(magnitude)

# 4. 检测快速运动（幅度 > 5.0）
if avg_magnitude > 5.0:
    fast_motion_frames.append(frame_info)
```

### 2. 运动模糊帧识别 ✅

#### `detect_motion_blur(frame_path, motion_magnitude, blur_threshold=100.0)`

**功能**:
- 结合拉普拉斯方差（静态模糊）和光流运动幅度
- 综合判断运动模糊
- 区分静态模糊和运动模糊

**算法**:
```python
# 1. 计算拉普拉斯方差
laplacian = cv2.Laplacian(img, cv2.CV_64F)
variance = laplacian.var()

# 2. 综合判断
is_blurred = variance < blur_threshold        # 静态模糊
has_motion = motion_magnitude > 5.0           # 有运动
is_motion_blurred = is_blurred and has_motion # 运动模糊

# 3. 模糊评分（考虑运动影响）
blur_score = min(100, variance / 2.0)
if has_motion:
    blur_score *= 0.8  # 运动降低评分
```

**返回结果**:
```python
(is_motion_blurred, blur_score, {
    'laplacian_variance': 85.3,
    'motion_magnitude': 6.5,
    'is_static_blur': False,
    'is_motion_blur': True
})
```

**判断逻辑**:
- **静态模糊**: 方差低 + 无运动 → 对焦问题
- **运动模糊**: 方差低 + 有运动 → 相机快速移动
- **清晰**: 方差高 → 无论是否运动都清晰

### 3. 拍摄建议生成 ✅

#### `generate_shooting_suggestions(motion_analysis)`

**功能**:
- 基于运动分析结果生成可操作的建议
- 多维度评估（速度、稳定性、一致性）
- 提供具体改进方法

**建议类型**:

| 指标 | 阈值 | 建议 |
|------|------|------|
| **运动速度** | > 8.0 | ⚠️ 相机移动过快，建议降低速度 |
| | < 1.0 | ⚠️ 相机移动过慢，建议增加速度 |
| | 1.0-8.0 | ✓ 运动速度适中 |
| **稳定性** | < 60 | ⚠️ 抖动较大，建议使用稳定器 |
| | 60-80 | 💡 稳定性一般，可改善 |
| | > 80 | ✓ 稳定性良好 |
| **一致性** | < 60 | ⚠️ 方向变化频繁，建议平滑运动 |
| | 60-80 | 💡 运动较平滑，有改进空间 |
| | > 80 | ✓ 运动轨迹平滑 |
| **快速帧** | > 5 | ⚠️ 检测到 N 个快速运动帧 |

## 📊 评分体系

### 运动稳定性评分 (0-100)

```python
stability_score = max(0, 100 - motion_std * 10)
```

- **90-100**: 优秀（三脚架级别）
- **70-89**: 良好（手持稳定）
- **50-69**: 一般（轻微抖动）
- **< 50**: 差（明显抖动）

### 运动一致性评分 (0-100)

```python
# 统计方向变化次数（> 45°）
direction_changes_ratio = direction_changes / total_pairs
consistency_score = 100 - direction_changes_ratio * 100
```

- **90-100**: 优秀（平滑轨迹）
- **70-89**: 良好（少量转向）
- **50-69**: 一般（频繁转向）
- **< 50**: 差（运动混乱）

### 综合质量评分

```python
overall_score = (stability_score + consistency_score) / 2
```

- **≥ 80**: 优秀，适合 3DGS 重建
- **60-79**: 良好，可优化
- **< 60**: 建议重新拍摄
