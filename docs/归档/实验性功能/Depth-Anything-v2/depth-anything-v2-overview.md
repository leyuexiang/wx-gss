## 💡 核心技术方案

### 方案 A: 混合深度（主推）
```
MASt3R 位姿 + (MASt3R 深度 ⊕ DA-V2 深度)
                              ↓
                    高置信度 → DA-V2（细节好）
                    低置信度 → MASt3R（尺度准）
```

**优势**: 结合两者优势，质量最高

### 方案 B: 替代深度（研究性）
```
MASt3R 位姿 + DA-V2 深度（对齐到尺度）
```

**优势**: 速度更快，但尺度对齐有风险

### 方案 C: 单图补充（快速）
```
if 单图 → DA-V2 深度 + 假设位姿
if 多图 → MASt3R 流程
```

**优势**: 扩展功能，1-2天完成

## 🔍 当前问题分析

### Phase 2 为什么失败？

**测试结果**:
- Phase 1（无深度）: Loss = 0.00479 ⭐⭐⭐⭐⭐
- Phase 2（MASt3R深度）: Loss = 0.00605 ↑26% ❌
- Phase 2.5（+ 位姿）: Loss = 0.00750 ↑57% ❌❌

**原因分析**:
1. `depth_reg_weight=0.1` **过大**
2. MASt3R 深度可能**不够精细**
3. 深度约束与光度 loss **冲突**

**假设**: DA-V2 深度更精细 → 深度正则化效果更好
