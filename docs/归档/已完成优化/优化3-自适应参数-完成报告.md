**方式 1: 完全自适应（推荐）⭐**

  -F "file=@photos.zip" \

## 🧠 推荐算法

### 推荐策略矩阵

#### MASt3R 后端（少视角，2-15 张）

| 图片数 | iterations | downsample | cap_max | cleanup | 质量等级 | 预估时间 |
|--------|-----------|-----------|---------|---------|----------|----------|
| **≤5 张** | 3000 | 2 | 500K | 0.12 | medium | 2.5 分钟 |
| **6-10 张** | 5000 | 1 | 800K | 0.10 | high | 4.8 分钟 |
| **11-15 张** | 7000 | 1 | 1000K | 0.08 | ultra | 7.0 分钟 |

#### COLMAP 后端（密集拍摄，20-500 张）

| 图片数 | iterations | downsample | cap_max | cleanup | 质量等级 | 预估时间 |
|--------|-----------|-----------|---------|---------|----------|----------|
| **20-30 张** | 5000 | 2 | 800K | 0.10 | high | 8.5 分钟 |
| **31-100 张** | 7000 | 2 | 1200K | 0.08 | ultra | 15 分钟 |
| **100+ 张** | 7000 | 4 | 1000K | 0.10 | high | 20 分钟 |

---

### 推荐逻辑

**决策因素**:
1. **图片数量** - 主要决策因子
2. **SfM 后端** - 少视角 vs 密集拍摄
3. **显存大小** - 自动调整 downsample
4. **质量与速度平衡** - 少视角快速，多视角更高质量

**关键原则**:
- 少视角（≤5张）：保守配置，避免过拟合
- 中等视角（6-10张）：高质量配置，最佳平衡点 ⭐
- 多视角（11+张）：极致配置，充分利用数据
- 密集拍摄（30+张）：长时间高质量训练

## 🔧 技术实现

### 核心函数

#### 1. `get_adaptive_params()`

```python
def get_adaptive_params(n_images, sfm_backend, gpu_memory_gb=8):
    """根据输入返回推荐参数"""
    if sfm_backend == "mast3r":
        if n_images <= 5:
            return {"iterations": 3000, ...}
        elif n_images <= 10:
            return {"iterations": 5000, ...}
        else:
            return {"iterations": 7000, ...}
    else:  # colmap
        # 密集拍摄逻辑
        ...
```

**特点**:
- 简单的 if-else 规则
- 基于经验数据
- 易于理解和调整

---

#### 2. `apply_adaptive_params()`

```python
def apply_adaptive_params(recommended, user_overrides):
    """合并推荐参数和用户参数，用户参数优先"""
    result = recommended.copy()
    if user_overrides:
        for key, value in user_overrides.items():
            if value is not None:
                result[key] = value  # 用户覆盖
    return result
```

**特点**:
- 用户参数优先级最高
- 支持部分覆盖
- 保持灵活性

---

### API 处理流程

```
1. 用户上传照片包
   ↓
2. 解析 ZIP，统计图片数量
   ↓
3. 检查是否启用自适应或有参数为 None
   ↓
4. 调用 get_adaptive_params() 获取推荐
   ↓
5. 调用 apply_adaptive_params() 合并用户参数
   ↓
6. 验证最终参数
   ↓
7. 提交训练任务
```
