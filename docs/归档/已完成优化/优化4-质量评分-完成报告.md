```

    ↓

  ├─ 提供解决方案
  └─ 参数优化建议
    ↓
输出到 train_stats.json
```

## 📊 评分标准

### 1. Loss 评分（权重 40%）

| Loss 范围 | 得分 | 评价 | 建议 |
|-----------|------|------|------|
| < 0.01 | 100 | 极佳收敛 | 无 |
| 0.01-0.02 | 95 | 优秀 | 无 |
| 0.02-0.05 | 80 | 良好 | 无 |
| 0.05-0.10 | 50 | 一般 | 增加 iterations |
| > 0.10 | 0 | 较差 | 检查数据质量 |

### 2. 高斯数量评分（权重 30%）

| 高斯数量 | 得分 | 评价 | 建议 |
|----------|------|------|------|
| 100K-1.2M | 100 | 理想范围 | 无 |
| 50K-100K | 60 | 偏少 | 增加 cap_max |
| 1.2M-1.5M | 85 | 偏多 | 考虑减小 cap_max |
| > 1.5M | 70 | 过多 | 减小 cap_max |
| < 50K | 20 | 严重不足 | 检查重建质量 |

### 3. 显存评分（权重 20%）

| 显存占用 | 得分 | 评价 | 建议 |
|----------|------|------|------|
| < 7.0 GB | 100 | 安全 | 无 |
| 7.0-7.5 GB | 80 | 较高 | 无 |
| 7.5-7.8 GB | 60 | 接近上限 | 优化参数 |
| > 7.8 GB | 40 | 危险 | 减小参数避免 OOM |

### 4. 训练效率评分（权重 10%）

| 速度 (iter/s) | 得分 | 评价 |
|--------------|------|------|
| ≥ 20 | 100 | 快速 |
| 10-20 | 85 | 正常 |
| < 10 | 70 | 较慢 |

## 🎯 使用方式

### 自动集成

训练完成后，质量评分会自动计算并保存到 `train_stats.json`。

**无需额外操作**，用户下载结果后即可看到评分。

### 查看评分

```bash
# 下载训练结果
curl -H "X-API-Key: $API_KEY" \
  http://host:12524/train/{task_id}/result \
  -o result.zip

# 解压并查看评分
unzip result.zip
cat train_stats.json | jq '.quality_score, .quality_rating, .recommendations'
```

**输出示例**:
```json

"优秀"
[
  "质量已经很好，无需调整",
  "如需更高清晰度，可尝试 downsample=1"
]
```

## 🔧 评分算法

### 加权平均计算

```python
总分 = 100
总分 -= (100 - Loss评分) × 0.4
总分 -= (100 - 高斯数评分) × 0.3
总分 -= (100 - 显存评分) × 0.2
总分 -= (100 - 效率评分) × 0.1

# 限制在 0-100 范围内
总分 = max(0, min(100, 总分))
```

### 评级映射

| 分数范围 | 评级 | Emoji |
|----------|------|-------|
| 90-100 | 优秀 | 🏆 |
| 80-89 | 良好 | ✅ |
| 70-79 | 一般 | ⚠️ |
| 60-69 | 及格 | ⚠️ |
| 0-59 | 较差 | ❌ |

## 💡 建议生成逻辑

### 自动建议规则

**Loss 相关**:
- Loss > 0.10 → "检查数据质量，建议增加 iterations"
- Loss > 0.05 → "可增加 iterations 到 5000-7000"

**高斯数相关**:
- < 50K → "可能重建失败，检查图片质量"
- < 100K → "可增加 cap_max"
- > 1.5M → "建议减小 cap_max 或启用清理"
- > 1.2M → "可考虑减小 cap_max"

**显存相关**:
- > 7.8GB → "建议增大 downsample 或减小 cap_max"
- > 7.5GB → "考虑优化参数避免 OOM"

**参数相关**:
- downsample > 1 且评分 ≥ 80 → "如需更高清晰度，可尝试 downsample=1"
- iterations < 5000 且 Loss > 0.02 → "可尝试增加 iterations"

## 🔬 技术细节

### 评分算法特点

**优点**:
- ✅ 简单直观，易于理解
- ✅ 多维度评估，全面客观
- ✅ 自动生成建议，实用性强
- ✅ 可扩展，易于调整权重

**局限性**:
- ⚠️ 基于规则，不是机器学习
- ⚠️ 权重固定，不适应所有场景
- ⚠️ 无法评估视觉质量（需要渲染）
