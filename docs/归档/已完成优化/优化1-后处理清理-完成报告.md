## 🎯 新增 API 参数

### `/train` 端点新参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `auto_cleanup` | bool | `true` | - | 是否自动清理杂点 |
| `cleanup_threshold` | float | `0.1` | 0.01-0.3 | 不透明度阈值 |

### 使用示例

#### 示例 1: 使用默认清理（推荐）
```bash
curl -X POST http://192.168.10.148:12524/train \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "file=@photos.zip" \
  -F "sfm_backend=mast3r" \
  -F "iterations=3000"
  # auto_cleanup=true, cleanup_threshold=0.1 (默认)
```

#### 示例 2: 激进清理（更多杂点）
```bash
curl -X POST http://192.168.10.148:12524/train \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "file=@photos.zip" \
  -F "sfm_backend=mast3r" \
  -F "auto_cleanup=true" \
  -F "cleanup_threshold=0.15"
```

#### 示例 3: 关闭清理
```bash
curl -X POST http://192.168.10.148:12524/train \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "file=@photos.zip" \
  -F "sfm_backend=mast3r" \
  -F "auto_cleanup=false"
```

### 清理算法

**过滤条件 1**: 不透明度过滤
- 删除 `opacity < threshold` 的点
- 默认阈值: 0.1 (sigmoid 转换后)

**过滤条件 2**: 距离过滤
- 计算每个点到中心的距离
- 删除距离 > 95% 百分位的点
- 有效去除背景漂浮点

## 🔧 技术细节

### 清理算法实现

```python
def clean_gaussians(ply_path, opacity_threshold=0.1, distance_percentile=95):
    # 1. 读取 PLY
    plydata = PlyData.read(ply_path)
    
    # 2. 提取位置和不透明度
    xyz = np.stack([vertex['x'], vertex['y'], vertex['z']], axis=1)
    opacity_logit = vertex['opacity']
    opacity = 1.0 / (1.0 + np.exp(-opacity_logit))  # sigmoid
    
    # 3. 过滤条件
    mask_opacity = opacity >= opacity_threshold
    
    center = np.median(xyz, axis=0)
    distances = np.linalg.norm(xyz - center, axis=1)
    dist_threshold = np.percentile(distances, distance_percentile)
    mask_distance = distances <= dist_threshold
    
    # 4. 组合并保存
    mask = mask_opacity & mask_distance
    cleaned_vertex = vertex[mask]

```

### 优点

- ✅ **简单有效**: 两个简单规则即可去除大部分杂点
- ✅ **可控性强**: 用户可调整阈值
- ✅ **性能好**: 清理耗时 < 1 秒
- ✅ **无损操作**: 不影响训练过程，仅后处理

### 局限性

- ⚠️ 可能误删边缘细节（如果阈值过高）
- ⚠️ 无法处理表面噪点（需要几何过滤）
- ⚠️ 中心点定义简单（使用中位数）

## 📊 监控指标

### 需要关注的指标

训练完成后检查：

1. **删除比例**: 应在 5-20% 之间
2. **最终高斯数**: 应 > 100K（避免过度删除）
3. **视觉效果**: SuperSplat 中查看是否有杂点
4. **文件大小**: PLY 应减小 5-15%

### 异常情况

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 删除 < 5% | 阈值过低 | 增大到 0.12-0.15 |
| 删除 > 30% | 阈值过高 | 减小到 0.08-0.10 |
| 视觉出现空洞 | 误删有效点 | 降低阈值或关闭清理 |
| 仍有很多杂点 | 清理不够 | 增大阈值或使用 DBSCAN |
