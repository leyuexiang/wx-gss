# 3DGS 清晰度优化第五轮记录

日期：2026-10-28。承接第四轮，先检查无掩码基线的重复性，不改动原推荐模型和线上默认流程。

## 1. 结论

完成两次相同配置的 7,000 次无掩码训练。实际初始化参数、相机、内参、全部原图摘要和 7,000 次抽样完全一致，最终主体峰值信噪比（PSNR）仍相差约 1.03 分贝，全图相差约 1.59 分贝。固定随机种子并不足以让当前训练逐位复现。

另外对同一初始化、同一张训练图重复四次渲染和反向计算，不执行优化器或增密：四次前向预测逐位一致，反向得到的位置梯度等存在约十的负七次方量级差异。因此已在完整反向链路中观测到数值非确定性；尚未单独定位具体内核，也未证明它能解释历史推荐模型与全部后续模型的差异。

本轮是诊断进展，没有产生优于推荐模型的新交付模型。原推荐及第四轮自动掩码实验候选保留，不能将第四轮约 5.27 分贝的单次对照差值当作稳定收益。

## 2. 实现

- 新增 `app/training_audit.py`。只在显式传入 `compare_strategy.py --audit-trace` 时保存真实初始化快照、带类型和形状的数组摘要、全部原图摘要，以及实际使用的视角索引序列。普通训练默认不启用，不承担显卡参数回读和快照开销。
- 保存位置为实验目录下的 `reproduction_audit/`：`initialization.npz`、`sampled_indices.npy` 和 `audit.json`。阶段写入只包含实际使用过的样本，不预先生成新的抽样序列，不改变随机数消耗。
- 新增 `compare_reproduction_audits.py`，比较初始化、原图、抽样、完成次数和实际配置；不完整抽样拒绝作为已完成实验。它只比较已记录的证据，不能替代逐算子定位。
- 新增 `probe_render_repeatability.py`，从真实快照加载参数和首个实际样本，固定参数重复渲染与反传，分别记录预测一致性和梯度差值。
- 审计快照不包含优化器状态，不能当作断点续训文件。本轮未引入新的依赖。

## 3. 实验条件与结果

源码隔离在 `/data/quality-repro-20261028`，使用第四轮固定实验镜像 `sha256:28da985cbc7fcad1332a186283056f488320ad3d1c1a4804b43f2324621f4aeb` 和只读源码挂载。未替换生产容器或修改源任务。

共同条件：60 视角、53 张训练图和固定七张验证图、1,059 × 1,885 像素、种子 42、原版风格增密、3,500 次停止增密、每 1,000 次阶段保存、总预算 7,000 次。地图仍使用全部 60 张重建，验证仅留出颜色监督；验证图继续用于阶段选择，不是新的独立测试集。

两次初始化压缩包中的实际数组以及完整抽样数组逐值相同，实际配置也相同；源相机与点云二进制文件摘要在结束后保持一致。两组首次 1,000 次阶段的点数已分别为 10,755 和 10,582，说明分歧在早期训练和增密期间已出现。不能把分歧全部归因于最终清理或阶段选择。

训练器统计耗时为 359.4 / 358.4 秒。两组最佳主体阶段均为 7,000 次，但均低于历史推荐模型的主体 30.3060、全图 29.6592。没有发布这两组回退结果为新的推荐。

四次固定参数探针的预测完全一致，后三次相对第一次的位置梯度最大绝对差分别约为 `1.21e-7`、`6.71e-8`、`4.47e-8`。不透明度、尺度和颜色梯度也有更小差异。这支持继续检查反向计算和增密阈值的敏感性，但尚不能证明某个具体算子是全部长期分歧的唯一原因。

报告位于 `/data/quality-audits/repro-20261028/`：`protocol.json` 记录镜像、源码归档和活动源码摘要、运行版本及地图摘要；`comparison.json` 保存最终核对结果，`render-probe.json` 保存探针数据。阶段曲线本机副本见 [训练曲线](../data/quality-audits/repro-20261028-stages.png)。训练器和审计模块在两轮开始前冻结；后续仅添加汇总脚本、探针和测试，没有修改运行中的训练器。

## 4. 验证与下一步

32 项检查通过，新增检查覆盖初始化快照独立性、Python/NumPy/训练框架随机状态不被消耗、真实抽样前缀保存、数组类型/形状/点顺序差异、不完整记录拒绝及比较差异识别。两次真实显卡长训练及四次固定参数探针均完成。

下一步先用短训练记录增密前后的参数和梯度差异，检查阈值判断是否放大微小数值差异；只在隔离实验中验证稳定化方案。随后使用多个重复运行评估较温和的掩码权重，同时报告逐视角回退与背景 MSE。不能只挑最高分运行，更不应盲目增加到 30,000 次。
