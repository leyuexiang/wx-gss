- 高质量预设每 1,000 次保存阶段，其他模式默认关闭；高级参数 `checkpointEvery` 可调整。需要启用留出验证。

- 预先指定按主体 PSNR 选择最佳阶段；没有主体标注的普通任务按全图 PSNR 选择。同分优先较早阶段。

## 4. 评估范围

这七张图已用于第二轮评估，本轮还用于选择阶段和时程。其指标属于验证集结果，不能再次称作独立测试集的无偏提升。

本轮复用的地图仍由全部 60 张输入重建，验证图仅留出颜色监督。第二轮训练图单独重建的严格协议结果继续保留，两种协议不混报。

增密停止也控制策略内部的相关裁剪、重置活动，实验只能说明该停止时程的综合作用。早期高斯点数差异、后续曲线和逐视角变化会一起核对，不能把差值全归于“点越多越模糊”。

### 4.1 依赖库重置条件诊断

核对服务器实际安装的 gsplat 1.5.3 源码，发现 `DefaultStrategy.step_post_backward` 中的不透明度重置条件为 `step % self.reset_every == 0 & step > 0`。按 Python 比较运算解析，其中位运算结果还必须大于零，该条件不会成立。检查第 3,000、6,000、9,000、12,000 步均未触发，不能继续把此前“配置为 3,000 次”解释为“已实际每 3,000 次重置”。

诊断及依赖源码摘要保存于 `/data/quality-audits/strategy-reset-diagnostic.json`。主对照两组继续使用冻结的原实现，避免运行中改变对照条件。

新增可选兼容策略，仅在识别到已确认的错误表达式时启用，复用依赖原有的重置函数，连同优化器参数绑定和动量状态一起更新；依赖实现改变时明确拒绝补丁，避免双重重置。普通服务默认仍保持现有行为，修正先用于单独实验。

新增第三组 `/data/quality-audits/monitor-resetfixed-stop7500-15000`，固定 15,000 次及 7,500 次停止增密，只启用重置条件修正，与主对照中的晚停止组比较。使用独立源码快照 `/data/quality-reset-fixed-20261027`，不覆盖前两组快照。18 项检查通过，新增检查验证重置时机、低不透明度保留、优化器重新绑定和动量归零。

## 6. 实验结果

三组实验均已完成。阶段指标使用固定的七张验证图和冻结主体矩形，属于阶段选择数据，不是新的独立测试集。

| 实验 | 最佳步数 | 主体 PSNR / SSIM | 全图 PSNR / SSIM | 最终阶段主体 PSNR | 说明 |
| --- | ---: | ---: | ---: | ---: | --- |
| 增密停止 3,500 | 12,000 | 30.6048 / 0.9565 | 29.2320 / 0.9726 | 30.3653 | 主体略优，全图低于当前推荐 |
| 增密停止 7,500 | 3,000 | 28.3103 / 0.9450 | 29.0804 / 0.9701 | 27.1000 | 过早出现验证回退 |

当前 7,000 次推荐模型的主体指标为 30.3060 / 0.9540，全图指标为 29.6592 / 0.9730。增密停止 3,500 的第 12,000 步只在主体矩形上提升约 0.30 dB、0.0025 SSIM，同时全图下降约 0.43 dB、0.0004 SSIM；综合收益不足以替换默认结果。

第 12,000 步阶段已发布为实验模型：`4a37109a495e4bff94850ba904e7ec0b`，名称为“手机视频-阶段选优-12000次”。[打开主体细节候选模型](http://localhost:3002/viewer?modelId=4a37109a495e4bff94850ba904e7ec0b)。当前推荐模型 `df6eea9f4e9847468da0dc789d33e5b2` 保持不变。阶段模型使用验证集选出，不能宣称对任意新视频泛化更好。

阶段曲线和完整逐步记录：`/data/quality-audits/monitor-comparison/summary.md`、`summary.json`、`training-stages.png`。本轮结论是：仅调整增密停止时机和修复不透明度重置，无法稳定消除长训练的新视角回退；下一阶段应转向主体掩码、曝光一致性和拍摄输入质量。

## 7. 下一阶段审计

已根据冻结主体矩形生成 GrabCut（矩形初始化的前景分割）原型。七帧前景比例为 18.5%–36.2%，其中部分帧把桌面反光或罐底边缘带入前景；原型只用于人工检查，未接入训练损失。

曝光审计显示七张验证图的主体内侧亮度范围约 44.53 灰度级，背景范围约 44.88 灰度级。不同视角的可见材质、反光和背景构成均会影响统计，不能据此证明存在自动曝光变化。原始图像、默认模型和当前推荐配置保持不变。

原型掩码：`/data/quality-audits/subject-masks-prototype-20261027`；曝光审计：`/data/quality-audits/exposure-audit-20261027.json`；本地脚本：[audit_exposure.py](../scripts/audit_exposure.py)。

亮度探索实验记录：3,000 次模型在调整后验证图上的主体 PSNR 为 24.4420 dB / SSIM 0.9344，原始验证图上为 28.7405 dB / SSIM 0.9401。后续复核发现，这次仅对七张验证图应用了亮度增益，53 张训练图未做同样校正，且全部图像重新编码；也缺少相同 3,000 次预算的原图基线。因此它不构成有效的曝光校正对照，撤回“亮度校正方案失败”的结论。保留数据供追溯，不据此否定其他曝光补偿方法；未部署该实验。

前端单物体拍摄提示已补充：锁定自动对焦与曝光、缓慢环绕、避免强背光和反光桌面。这些是针对本次审计发现的输入问题提示，不会改变训练参数。
