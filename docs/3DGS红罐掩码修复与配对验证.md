# 红罐掩码修复与配对验证（2026-10-29）

## 问题定位

直接对照冻结原图与掩码发现，第 1、109 帧等存在整块左侧罐身被删掉的情况。此前截图中破损不能仅归因于反光、4K 素材或相机分组：前景黑底监督和透明度损失会把错误掩码中的真实罐身作为背景惩罚，直接造成主体缺失。

原因是第一版红罐先验只选择最大的红色连通分量。条码旁的白色竖条和高光将一个罐身分成多个红色块，另半侧被丢弃，之后在错误的主体外接框内做图割也无法恢复。

## 修改

- 新增显式适配器 `red_can_v2`，合并面积足够、竖向重叠、横向接近的红色主体块，再生成粗轮廓。历史 `red_can` 行为保持不变。
- 新增 `evaluate_foreground_support`：检查掩码保留外部前景证据的比例。证据可以来自人工或先验，必须披露来源，不能当作图像真值。
- `repair_red_can_masks.py` 从冻结的 122 张原图生成独立第二版掩码，顶部/底部照片掩码不改动，原选帧不覆盖。
- 对全部 120 帧，使用第二版向内腐蚀后的粗轮廓作为专用证据，95% 覆盖门槛下旧掩码有 42 帧未通过、新掩码 0 帧未通过。这是先验一致性检查，不代表 42 帧都是半罐，也不证明新掩码准确。
- 准备入口对有明确失败结果的前景质量报告中止处理。无旧报告不会被伪装为质量通过；自动掩码继续标记为未人工确认。
- 训练器增加可选 `training_names`，按文件名冻结共同监督集合，拒绝未知文件、重复文件及与验证图重叠。未指定时保留原训练行为。

## 配对协议

实验目录：`/data/quality-audits/red-mask-paired-1000-20261029`。

1. 两组都使用任务 `b260061e0b4e42f3a7c5658ffa9dc87f` 的共享几何和全部 21,362 个初始化点。
2. 按旧任务冻结 101 张训练图和 14 张验证图。新恢复的 5 张视角不参与本轮颜色监督；几何与初始化仍使用全 120 张重建结果，因此不称为独立几何验证。
3. 两组只更换训练掩码。原图、相机、初始化、种子 42、损失权重、清理阈值和 1,000 次预算一致。
4. 短训练增密停止比例统一为 0.8，与历史 7,000 次完整训练不同，不能把本轮分数与历史直接相减归因。前 1,000 次训练的有效球谐阶数为 0，不用于判断最终反光或细节表现。
5. 两份导出模型统一用修正后的自动掩码和同一组固定相机评估，不将旧半罐参考与新完整参考各自计算的分数混在一起。
6. 保存实际初始化、每张原图摘要和全部抽样序列；配对结束核对一致性。即使输入一致，显卡算子和增密仍可能存在数值波动。
7. 本轮只做方向验证，不发布到模型列表，不覆盖正式模型，也不改生产默认参数。

## 实际结果

两组各 1,000 次训练均完成。`pair_verification.json` 核对所有初始化数组、原图摘要和完整抽样序列完全一致。以下都是按同一修正后自动参考、同一 14 个验证视角评估导出模型的结果：

| 项目 | 旧掩码训练 | 第二版掩码训练 |
| --- | --- | --- |
| 前景 PSNR | 15.0711 dB | 18.8387 dB |
| 轮廓 IoU | 0.91373 | 0.94810 |
| 掩码外平均透明度 | 0.06172 | 0.04096 |
| 掩码内透明度误差 | 0.04557 | 0.02732 |
| 黑底全图 PSNR / SSIM | 16.6087 / 0.84218 | 19.0616 / 0.86317 |
| 导出点数 | 25,186 | 25,445 |
| 训练与导出耗时 | 157.8 秒 | 161.1 秒 |

前景 PSNR 增加约 3.77 dB，掩码外透明度减少约 33.6%。查看全部 14 组固定相机的三列对照（修正参考 / 旧掩码模型 / 第二版模型），第 8、48、59、99、109、117 帧等侧面断裂和黑洞明显缓解，第 109 帧恢复了原先缺失的左侧罐身。盖顶模糊、反光、部分侧面纹理模糊仍存在，未作为最终清晰度验收。

只有一次配对和 1,000 次预算，没有重复统计，也没有完成 7,000 次成熟训练；参考来自正在验证的第二版掩码，本身存在偏差。因此结果用于确认“错误掩码会伤害主体”的方向，不能宣称通用去杂云通过，不能直接与历史不同几何、不同参考的 7,000 次分数比较。

62 项服务器回归测试通过。新增测试覆盖竖条分割主体的反例、证据覆盖检查、冻结监督集合、退化轨迹拒绝、圆周诊断的尺度不变性和配对输入不一致的阻断。Windows 本机执行本批 5 项定向测试通过。

主要结果文件：`comparison.json`、`pair_verification.json`、`trajectory_report.json`、`trajectory-and-shape.png`、`common-reference-contact.jpg`，以及各组 `common_reference/metrics.json` 和真实初始化快照。掩码原图对照位于第二版来源目录的 `support_report.json` 和四页联系表。

## 当前限制

全部 120 帧修正掩码已按四页联系表检查，半罐截断已消除；第 9、11、59、115 等帧盖顶仍有缺口，一些罐底仍包含反光转台，不能将自动覆盖检查代替人工确认。
