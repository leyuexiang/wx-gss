```python
temp_patterns = {
```

### 3. 自动清理旧任务 ✅

#### `auto_cleanup_old_tasks(data_dir, max_age_days=30, min_free_gb=10.0)`

**清理策略**:
1. 检查可用空间是否 < `min_free_gb`
2. 如果空间充足，跳过清理
3. 如果空间不足，按年龄排序任务（最旧的优先）
4. 删除超过 `max_age_days` 的旧任务
5. 清理到可用空间 > `min_free_gb` 为止

**示例**:
```python
# 空间不足 5 GB，清理超过 30 天的任务
result = auto_cleanup_old_tasks(
    data_dir='/home/3dgs/data',
    max_age_days=30,
    min_free_gb=10.0
)

# 返回
{
    'action': 'cleaned',
    'cleaned_tasks': 15,
    'total_freed_mb': 12580.5,
    'details': [
        {'task_id': 'abc123', 'age_days': 45.3, 'size_mb': 850.2},
        ...
    ],
    'current_free_gb': 12.3
}
```

**API 使用**:
```python
from app.task_state import get_task_state_manager

manager = get_task_state_manager()

# 保存任务

    'status': 'processing',

tasks = manager.list_tasks(status='processing')

# 恢复所有任务（服务启动时调用）
```

## 🔄 自动化建议

### 1. 定时清理任务

可以在 crontab 或后台任务中定时执行：

```python
# 每天凌晨 2 点自动清理
# crontab: 0 2 * * * curl -X POST http://localhost:12524/api/storage/auto-cleanup

# 或在后台任务中
import schedule
import time

def auto_cleanup_job():
    result = auto_cleanup_old_tasks(max_age_days=30, min_free_gb=10.0)
    print(f"自动清理完成: {result}")

schedule.every().day.at("02:00").do(auto_cleanup_job)

while True:
    schedule.run_pending()
    time.sleep(60)
```
