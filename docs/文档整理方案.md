```markdown
# 3DGS 训练服务

## 项目简介
基于 FlexGaussian 的 3D Gaussian Splatting 训练服务，支持多视角照片和视频输入。

## 快速开始
- 前端管理界面: http://192.168.10.148:3001
- 后端 API: http://192.168.10.148:12524
- API 文档: http://192.168.10.148:12524/docs

## 核心功能
- 多视角照片 → 3DGS 模型训练
- 视频自动抽帧（支持智能去重去模糊）
- 模型压缩优化（LightGaussian/Mini-Splatting/Compact3D）
- Web 管理界面（科技风格）

## 文档导航
- [API使用手册](./API使用手册.md)
- [视频训练设计分析](./视频训练设计分析.md)
- [项目整合说明](./项目整合说明.md)
- [功能设计文档](./docs/核心设计/功能设计文档.md)

## 技术栈
- 后端: FastAPI + Celery + Docker
- 前端: Vue 3 + Element Plus + Vite
- 训练: FlexGaussian + COLMAP/MASt3R
- GPU: CUDA 12.8.1
```
