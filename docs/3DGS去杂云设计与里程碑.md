# 3DGS 去杂云设计与里程碑

日期：2026-10-29。目标是减少白色雾状遮挡与错误几何，同时保留文字、金属高光和主体边缘。当前推荐模型 `df6eea9f4e9847468da0dc789d33e5b2` 保留；本设计不按白色直接删点。

## 1. 依据与边界

- 双边网格（Bilateral Grid）建模每张训练图的局部光度变化，减轻曝光、白平衡等差异对几何的干扰。它不是简单均衡直方图，也不是修复已有模型的后处理滤镜。
- 稀疏深度（Sparse Depth）从相机重建观测轨迹提取可靠三维点，在对应像素处约束渲染的相机轴向深度。纯色墙可能缺少有效观测，不能保证恢复所有平面。
- 当前项目只有 MASt3R 稠密深度的相关性损失，COLMAP 任务没有使用稀疏深度。茶罐地图有 5,324 个三维点，单图关联观测 66–778 个；可靠性过滤后的数量需重新统计。
- 第五轮已确认同初始化、同抽样仍有训练波动。因此单次高分不能作为算法收益；本轮不先修改增密、不叠加掩码，避免无法归因。

## 2. 设计

### 稀疏深度

使用图像实际关联且具有足够轨迹长度、有限重投影误差的三维点。与原训练共用归一化、相机内参和去畸变图，深度为相机坐标 Z，不是欧氏距离；只在可见且落在图内的位置监督，不将稀疏数据插值填满纯色墙。

损失采用逆深度平均绝对误差（L1），单独配置权重。无有效深度的训练帧明确统计并跳过；全部训练帧无有效深度时失败。默认关闭，与既有 MASt3R 深度、位姿微调暂不混用。验证图不参与深度或颜色损失；原地图使用全部视角的限制继续披露，严格训练图单独重建协议另列实验。

### 双边网格

训练图各有独立低分辨率网格，以图像位置和亮度切片得到局部仿射颜色变换；从恒等变换初始化，加入总变差平滑约束。仅作用于颜色损失，深度不经过颜色变换。网格自身的初始化不得消耗基线随机序列。

验证与 PLY 交付首先评估不经过验证图拟合的高斯模型，不用验证图学习颜色校正来抬分。网格属于训练外观参数，独立保存，不声称标准 PLY 包含这些参数。本次根据论文的局部仿射模型编写最小实现，复用训练框架已有的网格采样功能；没有复制第三方源码，也不宣称与官方完整实现等价。后续引入第三方实现时保留许可证和来源。

## 4. 对照协议与验收

四组固定原始图、地图、53/7 颜色训练验证划分、像素尺寸、初始化、种子、增密时程和训练预算；每组启用审计。初始深度权重、网格大小和正则权重在实验前记录，探索调参另建目录。至少两次重复只是初步稳定性检查，不构成统计显著性证明。

固定七张验证图及已有主体矩形，报告峰值信噪比（PSNR）、结构相似性（SSIM）、背景均方误差（MSE）、逐视角及最差视角；重点检查第 40/56 帧。未经颜色拟合的导出模型为主指标。深度辅助指标须标为重建点监督残差，不解释为独立几何真值。点数和删点比例不能代表杂云数量。

验收目标是主体 PSNR 争取约 1 分贝改善、视觉雾状遮挡减轻且无明显新增孔洞，背景 MSE 和困难视角不明显回退；这是待验证目标。若目标是孤立茶罐资产，另行设计背景裁除及多视角掩码/遮挡一致性，不能与保留室内背景的任务混报。

### 相机坐标问题与处理

深度坐标审计发现，历史数据加载器将相似变换直接左乘完整相机到世界矩阵，使旋转部分也乘上场景尺度。该茶罐数据的旋转矩阵奇异值约为 0.1987166，而不是 1。对齐图像投影并不足以证明轴向深度单位正确，因此不能在这种约定下直接解释归一化深度。

新增实验开关 `--rigid-normalization`：仅缩放、平移相机中心，保留旋转正交性，并与点云采用同一世界归一化。稀疏深度实验强制要求这一开关；四组全部使用修正后的相机约定，不能只给深度组修正相机。历史模型的查看和评估继续保留旧约定，未直接覆盖生产数据。该修正尚未通过长训练验证，不宣称已解释历史全部杂云或训练波动。

修正后真实相机旋转的奇异值为 `[1, 1, 1]`，单位检查确认投影不变而相机 Z 随世界尺度同步缩放。独立评估与阶段发布脚本也支持保持实验相机约定，后续发布不能使用历史约定重新评估。
